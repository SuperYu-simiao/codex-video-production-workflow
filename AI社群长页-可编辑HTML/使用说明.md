# 域新AI长页可编辑 HTML

## 怎么使用

1. 双击 `index.html`，用浏览器打开。
2. 点击右上角“开始编辑”。
3. 蓝色虚线里的文字可以直接修改。
4. 点击人物头像或二维码区域，可以选择本地图片替换。
5. 点击“保存草稿”，修改会保存在当前浏览器。
6. 点击“导出 HTML”，会下载一份包含当前文字和图片的独立 HTML 文件。

## 小提示

- 推荐头像比例约为 4:5，二维码使用正方形图片。
- 选择图片后会直接写入导出的 HTML；如果图片很大，文件也会随之变大。
- `Command/Ctrl + S` 可以快速保存草稿，`Esc` 可以退出编辑状态。
- 打印或导出 PDF 时，编辑工具栏会自动隐藏。
