# 特效库模板1：调用说明

## 以后直接使用的提示词

```text
请调用本机视频工作流的“特效库模板1”。
沿用暗场透视网格、单一强调色、真人/证据分层、语义转场和阅读停留规则。
先读取：
1. 动效库/特效库模板1/特效库模板1.json
2. 动效库/特效库模板1/config/模板配置.example.json
3. 动效库/特效库模板1/README.md
4. 当前项目的 project.json、逐字稿、素材盘点和授权说明

按逐字稿语义从模板注册表挑选镜头，不要按固定秒数乱铺特效。
只替换人物、公开网页截图、录屏、标题、步骤和字幕；保留已校准的运动参数。
人物要按脸部焦点居中裁剪，录屏优先完整展示并单独处理隐私遮挡。
没有内容变化的转场/背景使用已有缓存；只改动的镜头局部渲染，最后再做一次合成渲染。
先输出特效映射与素材槽位表，再按当前项目授权进入预览和成片阶段。
```

## 执行顺序

1. 用逐字稿标出语义 cue：开场人物、产品名、结论重音、概念解释、安装步骤、三个 Skill 章节、证据举例、收束。
2. 用 `特效库模板1.json` 的 `cueRules` 选择一个主模块；同一语义不要同时叠两个主转场。
3. 把当前视频的素材路径填入 `config`，所有路径限定在当前项目，不引用本期旧项目素材。
4. 对真实网页和 GitHub 首页做非登录公开页核验；对录屏做隐私审计和完整性检查。
5. 先渲染单镜头或局部范围检查文字、人物焦点和录屏可读性，再合成整片。

## 局部渲染策略

- 只改镜头文案或截图：复用动效参数，只局部渲染该镜头。
- 只改字幕：不重做动效，沿用相同的 master timeline，只重新合成字幕层。
- 只换 BGM：模板的 BGM 轨独立，输出无 BGM 版和带桥接 BGM 版。
- 改变画幅、fps、镜头时长或主转场：视为模板新变体，需要重新做一次代表帧 QA。

Remotion 示例（帧范围按当前项目时间线替换）：

```bash
npx remotion render src/index.ts Template1Preview out/shot.mp4 --frames=0-149 --props='@config/video.config.json'
```

实际 CLI 参数以当前 Remotion 版本帮助为准；不把预览文件冒充最终成片，也不覆盖原始素材。

## 模板变体规则

- `T1-A / 轻解释`：`definition-sop` + `install-steps` + `recording-runway`，适合教程和产品操作。
- `T1-B / 证据调研`：`research-hero` + `evidence-strip` + `vertical-sources` + `result-bento`，适合调研、论文和专业信息源。
- `T1-C / 强开场`：`hero-news` + `word-fracture` + `kill-shot` + `skill-wall` + `bridge-flock`，适合短视频前 15 秒。

变体只改变模块顺序和内容槽位，不修改基础网格、字幕安全带、人物焦点居中和隐私规则。
