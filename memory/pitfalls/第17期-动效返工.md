# 第17期 grokbot 动效返工四次（踩坑经过）

## 错在哪（四次都返工）

1. **第一次（v1）**：把 16 个特效段做成「套 demo 卡灰阶效果 + ffmpeg 拼装」。用户判定「完全不对」。
   - 正确方向：第6期「手写定制镜头组件（真实素材 + 品牌色 + 词级对齐 + 人物 PIP）+ Remotion master 合成 25fps」。

2. **第二次（v2 开头小样）**：画面「人物口播一直展示」，没有做到「一句话切换一个画面/动效」。
   - 正确规则早已写在 `memory/reference/特效使用模板.md` §0/§2/§3 与 `effects.json` 的 states + transition_policy（`state_change_requires_effect=true`、`align_to: sentence boundary`），**读到了却没执行**。

3. **第三次（小样做得太长）**：开头小样 v2 做了 43.9s。用户明确：小样只做开头总起段（约 10–20s），到正文第一个分段前结束，否则方向不对时浪费大量时间。

4. **第四次（不读 demo TSX 就手写简化动效，100% 禁止）**：v3 的「数字滚动/光标/卡片砸入」是我自己手写的简化版，没有去读 video-shotcraft 仓库对应卡的 demo TSX 继承运动结构；上一版开头的 3D 巡礼（graze-face-tour）也被换成了简单大字。违反「特效名相同≠观感相同，必须读完整镜头卡 + demo TSX」。用户实报「你是对照仓库特效提示词做的吗？感觉并不是，是不是偷懒了」「上一版第一个特效怎么换没了」。

## 根因（不是"没读到"，是"没执行、没门拦住"）

- 关键基准（特效使用模板、第6期黄金参考）只被标了「必读」，没有被「强制门」锁死：没有要求产出勾选记录，读到也可能不做。
- 逐字稿没有先按语义句群拆节点，就凭感觉堆特效卡，导致人物全屏贯穿、画面不切换。

## 下次怎么不犯（机制，不是靠记性）

1. 动效方向锁定前先确认是「手写定制镜头 + Remotion master 合成」，禁止「套 demo 卡 + ffmpeg 拼装」。
2. 逐字稿必须先按语义句群拆节点（约 2–3 句一节点），每个节点落到「语义 → 主动效 → 人物状态(P0/P1-R/P2/P3) → 转场」一行并写进特效映射；人物只有纯口播叙述/观点/情绪句才 P0 全屏，其余退小窗或隐藏。
3. 出小样前逐项过 `特效使用模板.md` §5 选型自查清单，勾选结果留在 `04-动效与包装/特效映射-<slug>.json`；未勾选不出小样（workflow.json preview gate 已强制）。
4. 小样只做开头总起段（约 10–20s），到正文第一个分段前结束；效果确认后再扩展，不一次憋长小样。
