# 制作约束（必保行为）

- 真人原片、原始录屏、文稿、已归档素材只读；转换写副本，项目产物写对应阶段目录。凭据不读不记录；当前任务授权可本地读素材，但默认不提交、推送或上传素材、转录、缓存、成片。
- 每次视觉状态变化有语义匹配的转场；同一状态内的口误精剪可干净跳切。每镜一个主运动，落定后保留阅读停顿，阅读真实网页时不持续漂移。
- PIP按脸和躯干定位，避让 UI、手势与字幕；同一连续口播通过位置、裁切和遮罩重构，不重新起片制造假连续。
- 真正插入暂停时拆开源片轨并停住源音，插入后从同一源帧恢复，所有后续轨道共用一次补偿。盖图或静音一个持续前进的视频不算暂停。
- 字幕跟随真实音频；已确认模板按默认使用，不擅自改外观。可复制文本逐字使用已提供原文，导演备注不进入观众画面。
- 修改范围以用户反馈为准，已满意组件保持基线。原始事实不足时说明缺口，不虚构 UI、操作成功、代码、百分比或资料包。
- 代理、抽帧、进程检查与录屏/预览/渲染/终止进程分开；`.gitignore` 不代替 watcher 配置。
- 动效必须走「手写定制镜头组件 + Remotion master 合成」，禁止「套 demo 卡灰阶 + ffmpeg 拼装」；逐字稿先按语义句群拆节点（约 2–3 句一节点），每个节点只一个主动效，人物只有纯口播叙述/观点/情绪句才 P0 全屏，其余退小窗或隐藏（P1-R/P2/P3）。
- 出小样前逐项过 `memory/reference/特效使用模板.md` §5 选型自查清单，勾选结果留在 `04-动效与包装/特效映射-<slug>.json`；未勾选不出小样。违反后果：用户实报「完全不对」「不要总是人物口播展示，一句话切换一个画面」，第17期返工两次。
- 小样只做开头总起段（约 10–20s），到正文第一个分段前结束，效果确认后再扩展；不一次做长小样，否则方向不对时浪费大量返工时间。
- 【100% 禁止】动效实现前必须读对应特效卡的镜头卡全文 + demo TSX 原文，继承其缓动/时值/纵深/运动模糊/布局，只替换素材/文案/品牌色；禁止凭卡名手写简化动效、禁止换掉已满意特效。每个特效须在 `04-动效与包装/特效映射-<slug>.json` 记录镜头卡路径 + demo TSX 路径 + 继承的参数；未记录不出小样。违反后果：用户实报「你是对照仓库特效提示词做的吗？感觉并不是，是不是偷懒了」，第17期 v3 返工。

## 补充约束（2026-09-17 第18期完整成片实报）

- **段帧号以导演时间线为准，不自行估算**：`02-转录与剪辑决策/导演时间线-<slug>.json` 的 `source_in_frame`/`source_out_frame` 是各段边界的唯一权威（例如 S4 源 2500→3506 是 1006 帧，不是 1000）；Remotion 每段的 `S*_SOURCE_START` 与 `S*_FRAMES` 必须逐字抄导演时间线，段落边界不准、差几帧会让口播被截断或下一段开头重复。
- **录屏素材进 Remotion 前必须先转码**：原始录屏多为 60fps、4K/近4K、含自带音轨。进 25fps 工程前用 ffmpeg 统一转成 `-r 25`、`scale=1920:1080`（`force_original_aspect_ratio=decrease` + `pad` 补黑到 16:9，补底色用工程深底 `0x0a0d12`）、`-an` 去音轨（声音只用口播视频自带录音，录屏音轨一律不要）、`-c:v libx264 -crf 22`，产物写 `05-Remotion工程/public/assets/`。违反后果：60fps 源直接塞 25fps 工程会导致录屏帧率错位、画面与口播脱节。
- **人物不要一直放小窗（2026-09-23 第20期成片实报）**：只有特效句/录屏句才用 PIP 小窗；停顿/呼吸句（1–2s 空档）必须切回人物**全屏口播**，全屏时**不留小窗**。原因：特效在停顿时会显得"画面突然卡住"，人物全屏口播正好填补空档、声音连续。全屏↔小窗约 12 帧平滑过渡（单人物 Video 全程播放不重起，muted=false 保持口播连续）。违反后果：用户实报「人物不要一直放小窗」，第20期开头样片返工一次。
