## 1. 一句话结论

这类开头的核心不是单一版式，而是一条反复使用的视觉降级链：

**真人全屏建立信任 -> 主题贴纸把抽象概念变成梗 -> 真人缩进左侧竖框、右侧逐项讲结构 -> 真人再缩成左下圆形头像、把主舞台让给产品画面 -> 全画面压暗，三层大字给出结果承诺 -> 硬切回真人继续正片。**

人物不是随意缩小，而是始终承担不同功能：

1. 全屏真人：负责开场、情绪和可信度。
2. 左侧竖框：负责陪讲，右侧承担信息结构。
3. 左下圆形头像：只保留“人在讲”的存在感，把 70% 以上空间让给手机/案例和大字。

## 3. 人物与背景的三种标准状态

以下坐标以**有效 16:9 画面**为准，百分比是本片观测；1920 x 1080 数值是等比换算，方便复刻。

### `P0` 真人全屏

**[观测]**

- 画面覆盖：100% x 100%。
- 人脸中心约在 `(50%, 30%)`；上方留约 7%-10% 头顶空间。
- 景别：胸口以上中近景，双手抬起时仍尽量不出框。
- 背景：紫/洋红主灯，右上有粉色闪电灯，左右有暖色小灯和虚化工作台。
- 字幕：有效画面底部约 `y=86%-91%`，黑色圆角底、白色窄体字。

**[复刻建议]**

- 人脸不要贴顶；手势是这个模板的节奏来源，左右至少留各 18% 动作空间。
- 全屏阶段不要同时堆课程卡片，最多出现一个 Logo 或一个超大关键词。

### `P1` 左侧竖向圆角人物框

**[观测]**

- 人物框：约 `x=5.2%, y=8.3%, w=30.0%, h=82.0%`。
- 1920 x 1080 参考：`x=100, y=90, w=576, h=886`。
- 圆角：约人物框宽度的 6%-8%，1920 画布约 36-48 px。
- 裁切：从全屏源直接裁成接近 `2:3` 的竖框；脸居中略偏上，胸口保留，手臂允许被左右边缘裁掉。
- 这不是小 PIP。人物仍占画面约三分之一，是信息页的第二主角。

右侧路线图区：

- 标题：约 `x=39%, y=4%, w=56%, h=14%`。
- 节点线：约 `x=47.5%`，纵向覆盖 `y=29%-72%`。
- 三张卡：约 `x=52%, w=31%`；单卡高约 14%，纵向中心约在 30%、50%、70%。
- 卡片只有描边，没有实色填充，纸张纹理透出来。

### `P2` 左下圆形头像 + 产品主舞台

**[观测]**

- 人物圆形直径约画布宽度的 15%，即 1920 画布约 288 px。
- 圆心约 `(7.5%, 86%)`，左边和下边都略微出画，形成“陪讲头像”而不是独立卡片。
- 裁切只保留头颈和少量肩部；脸中心约在圆形的 50% x 47%。
- 手机主视觉约在 `x=53%-86%`，从画面下沿进入，顶部停在 `y=20%-22%`。
- 路线图缩至左半区，手机占右半区，人物只负责持续陪伴。

**[复刻建议]**

- 如果字幕与头像冲突，字幕向中间移动，不要把头像抬高到遮住步骤卡。
- 圆形头像适合产品演示、截图、数据表和手机画面；没有主素材时不要无理由缩成圆形。

### `P3` 压暗承诺层

- `P2` 的全部底图保留，但加黑色遮罩，观感约 70%-78% 黑。
- 人物头像仍可辨认，手机和路线图退到“证据背景”。
- 中央大字成为唯一一级信息：首行黄色数字/数量，中行白色场景/动作，末行黄色结果/收益。
- 这是开头的“价值承诺封口”，不是普通字幕。

## 4. 纸张课程图模板

### 4.1 固定骨架

1. 全屏暖白/冷白纸张纹理，不使用纯白色块。
2. 顶部一行超大黑色课程名，带书名号，字重极粗。
3. 左侧人物或左侧路线图，右侧根据口播放步骤卡/手机/截图。
4. 进度线使用黑色圆环节点 + 竖向虚线，节点与三张卡中心对齐。
5. 卡片使用蓝、黄、紫三种细描边，圆角中等，内部保持透明。
6. 底部字幕永远独立于模板正文，黑底白字，便于在纸纹和人物上都可读。

### 4.2 建议色板

### 4.3 字体层级

- 课程名：极粗黑体/展示黑体，优先横向厚重，不用细长科技字。
- 步骤卡：重黑压缩字，字号约单卡高度的 60%-72%。
- 大字承诺：粗黑/粗斜体，带硬阴影和轻微辉光。
- 字幕：窄体或压缩无衬线，保持单行优先，避免抢主标题。

## 5. 动效语法

### 5.1 作者常用的五种动作

1. **同源人物几何变形**：全屏 -> 圆角竖框 -> 圆形头像，靠 `scale + translate + clip-path/border-radius` 连续完成。
2. **口播逐项填空**：先显示空卡骨架，再随“安装 / 基础 / 高级”逐项填入，不提前泄露全部信息。
3. **产品画面夺主位**：手机/截图从下方或右下进入，同时人物缩小，构图主次发生明确交换。
4. **暗场大字封口**：底图不换，只压暗；数字、场景、结果三层大字顺序出现。
5. **一词一特效**：奶妈 -> 护士服贴纸；含金量 -> 金币雨；游刃有余 -> 超大背景字。抽象口播被具象成一个强记忆图像。

### 5.2 复刻参数（非源工程参数）

| 动作 | 建议时长 | 建议曲线/处理 |
|---|---:|---|
| Logo 小入场 | 0.25-0.40 s | `easeOutCubic`，x/y 位移 20-40 px，透明度 0->1 |
| 贴纸冲入 | 0.35-0.55 s | scale `0.65->1.06->1`，前 6-8 帧方向模糊 |
| 全屏转竖框 | 0.60-0.85 s | `easeInOutCubic`；位置、缩放、圆角同一条曲线 |
| 步骤文字填入 | 每项 0.35-0.55 s | scale `0.25->1.08->1` 或字符组装；出现间隔跟口播 |
| 竖框转圆形 + 手机入场 | 0.40-0.55 s | 两元素同步，手机略晚 2-3 帧 |
| 暗场遮罩 | 0.15-0.25 s | opacity 快速到 0.72，避免慢慢变灰 |
| 三层大字 | 每层 0.40-0.80 s | y 位移 30-70 px、残影 2-3 层、投影 12-24 px |
| 返回真人 | 1 帧硬切 | 不做溶解，清楚区分包装段与正片 |

### 5.3 不要误做成这些效果

- 不要把 `P1` 人物缩成普通角落小窗；她在课程图阶段仍然是 30% 宽的大视觉锚点。
- 不要在三张步骤卡里一开始就把文字全填满；“空架子 -> 逐项激活”才有口播同步感。
- 不要让手机简单覆盖人物框；正确动作是人物先降级为圆形，手机再占主舞台。
- 不要把平台 UI 当包装元素。
- 不要给所有口播都加金币、辉光和大字；强特效只用在能被具象化的关键词上。

## 8. 图层顺序

从底到顶：

1. 实景真人原片或纸张纹理底。
2. 产品/手机/截图主体。
3. 人物蒙版层（全屏、竖框、圆形共用同一素材）。
4. 路线图虚线、节点、卡片描边。
5. 课程名和步骤文字。
6. 关键词贴纸、护士服、金币等主题特效。
7. 暗场遮罩。
8. 承诺大字与残影。
9. 底部字幕。

人物贴纸需要跟随脸/肩部时，帽子放在人物前景层，巨大“奶/级”放在人物后方；这样人物仍然可读。

## 11. 最终风格 DNA

这是一个“**真人可信度 + 教程信息图 + 关键词娱乐化**”的开头系统：

- 真人从不消失，只是随着信息密度从主角降级为陪讲者。
- 背景从紫色实景切到白色纸张，是从“聊天”进入“教学结构”的视觉信号。
- 每次缩小人物，都必须同时放大一个更重要的信息对象。
- 每个强特效都对应口播中的一个关键词，而不是为热闹随机添加。
- 开头最后一定用数字化承诺封口，并硬切回真人，让观众知道教程正式开始。
