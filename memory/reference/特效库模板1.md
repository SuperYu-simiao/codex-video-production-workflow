# 特效库模板1：暗场网格 + 语义证据动效

> 版本：1.0.0  
> 来源：第9期《Codex 三个 Skill》v6 成片包装  
> 类型：可复用特效模板，不是固定视频工程，也不包含本期隐私素材。

## 一句话视觉定义

用低对比黑场透视网格承接真人口播，把每一句关键语义转译成一个可读的视觉隐喻：人物/新闻是全屏 terrain，产品名是碎片聚合，能力是节点接入，Skill 是真实公开首页墙，操作是完整录屏，专业内容是证据卡片，思考流程是时间线。

## 适用范围

- AI 工具、Agent、Skill、插件、工作流和产品功能解释。
- 有真人口播，同时需要网页截图、GitHub 页面、录屏和概念图表的教程。
- 需要节奏明确、但不能用连续炫技动画盖住口播的短视频。

不适合：纯人物访谈、复古新闻纸质拼贴、需要长时间展示复杂表格但没有足够原始截图的内容。若主题改成财经调查或历史档案，应调用风格库4，而不是强行套用本模板。

### 字体与字幕

- 中文和字幕：`PingFang SC, Hiragino Sans GB, Noto Sans CJK SC`。
- 英文、卡片编号和来源标签：`SFMono-Regular, Menlo, Monaco, Consolas`。
- 1920x1080 默认字幕字号 48px，位于底部 15% 安全带，黑色半透明底块。
- 关键词只用一个镜头强调色，不使用彩虹渐变；可复制命令必须逐字保留并独立于字幕。

### 人物构图与安全区

| 状态 | 默认构图 | 规则 |
|---|---|---|
| `fullscreen` | 人物全屏 | `object-position` 以脸部焦点为准，通常 `50% 50%` |
| `left-rail` | 左侧约 30% 竖栏 | 默认 `x=3.5% y=16% w=30% h=68%`；本期焦点 `80% 34%` |
| `right-rail` | 右侧约 27% 竖栏 | 默认 `x=69% y=16% w=27% h=66%` |
| `pip-br` | 右下角小窗 | 只在网页/文档需要全屏阅读时使用 |
| `hidden` | 暂时隐藏人物 | 只用于密集证据或停顿桥接，音频保持连续 |

人物只在语义状态改变时移动或换裁剪；不要每句话跳一次。素材全屏时人物退到安全角小窗或隐藏，字幕仍属于主画面。

## 常用组合

### T1-A：教程解释

`hero-news → definition-sop → identity-switch → install-steps → recording-runway → process-flash → clone-assistant`

重点是“讲清楚”，录屏是主证据，动效只负责建立关系和引导视线。

### T1-B：深度调研

`research-hero → evidence-strip → vertical-sources → result-bento`

重点是“来源真实、内容可读”，页面静止后再让观众阅读，不用持续扫光。

### T1-C：强开场

`hero-news → word-fracture → integration-hub → kill-shot → skill-wall → bridge-flock`

前 15 秒建立人物、产品、结论和三个能力；桥接卡只放在明确停顿处。

## 素材槽位规范

| 槽位 | 输入 | 处理 |
|---|---|---|
| `heroImage` | 公开新闻/人物图 | 真实来源；全屏时适度推近，不遮主体 |
| `centerImage` / `pageImage` | 官网或 GitHub 非登录首页 | 记录 URL、日期和公开范围；不显示账户栏 |
| `recording` | 用户录屏 | 优先 `contain`；先做隐私 mask，再决定是否裁切 |
| `documents[]` | 财报、法律、论文截图 | 只用授权或公开来源；正文可读，不用假数据 |
| `conceptImage` | 用户图表或明确概念示意 | 标注“概念示意”时不冒充真实页面 |
| `steps[]` / `milestones[]` | 逐字稿里的步骤 | 逐字保留；不要凭空补 API key 或路径 |
| `safeCode[]` | 脱敏代码/伪代码 | 禁止真实 token、账户、私有域名和本地路径 |

## 转场与声音

- 每次画面状态变化只有一个主转场：`aurora-bloom-bg-flip`、`line-carry-transition`、`mosaic-reframe`、`flash-cut` 或 `card-flock-tumble` 任选其一。
- `card-flock-tumble` 只作为桥接或章节换气，不要在连续口播中盖住语句。
- BGM 默认不铺全片；只在用户指定的停顿桥接段进入。无 BGM 版保留 SFX，带 BGM 版单独输出。
- 动效完成后留静止阅读时间；重音可以短，证据不能快。

## 缓存与渲染策略

模板把模块标成三类：

- `overlay-cacheable`：网格、碎片字、时间线、提示词密度等内容独立层；内容不变时可直接复用缓存或透明叠加片段。
- `transition`：桥接、闪切和章节换场；同一转场参数可以跨视频复用。
- `content-bound`：网页截图、录屏、人物和字幕参与合成；换内容时只重算受影响镜头。

未来调用模板时，不需要重新设计、找卡、调缓动或重写基础组件。若人物、文案、截图或时长改变，仍需对改变的镜头重新编码，最后做一次全片合成；“不重复渲染”在这里指不重复渲染未改变的镜头和动效壳，而不是跳过最终视频编码。

## 隐私与版权

- 模板目录只存配置、说明和无项目依赖的代码，不复制本期真人原片、录屏、字幕缓存或成片。
- 公开首页必须是非登录页；新闻图片、论文、财报、法律页面记录来源和授权范围。
- 本期曾做过的本地工作区名称、账户头像、书签、路径和任何 key 不能进入模板。
- 水印是否保留由当前项目决定，不能把本期水印当成模板固定元素。

- [ ] 录屏完整展示，隐私遮挡没有盖住有效操作。
