# 风格库3：可直接套用的视频开头模板

## 核心公式

`真人全屏钩子 -> Logo/关键词梗 -> 左人右信息的纸张路线图 -> 左下圆形人物 + 产品画面 -> 压暗底图 + 数字承诺 -> 硬切回真人`

## 23 秒时间轴

| 时间 | 口播写法 | 人物 | 背景/动画 |
|---|---|---|---|
| `0-4 s` | “今天用一条视频讲清楚【主题】” | 全屏中近景 | 紫色/品牌色实景，只放字幕 |
| `4-7 s` | “这是【产品】的【定位】教程” | 仍全屏 | 左上 Logo；一个大关键词 |
| `7-10 s` | 说一个能被具象化的形容词 | 仍全屏 | 只做一个贴纸梗：服装、帽子、道具或超大背景字 |
| `10-18 s` | “从【步骤1】到【步骤2】，再到【步骤3】” | 全屏连续缩到左侧竖向圆角框 | 白色纸纹；标题固定；三张彩边卡随口播逐项填入 |
| `18-20 s` | “还会演示【手机/案例/结果】” | 竖框连续缩到左下圆形头像 | 手机/截图从右下进入并成为主视觉 |
| `20-23 s` | “用【数字】个【场景】，让你【结果】” | 圆形头像保留 | 底图压暗；黄数字、白场景、黄结果三层大字依次出现 |
| `23 s` | “正式开始” | 1 帧硬切回全屏 | 进入正片 |

## 1920 x 1080 布局参数

| 元素 | x | y | w | h/直径 |
|---|---:|---:|---:|---:|
| 左侧竖向人物框 | 100 | 90 | 576 | 886 |
| 顶部课程标题区 | 750 | 45 | 1080 | 150 |
| 进度线中心 | 912 | 310 | 1 | 470 |
| 三张步骤卡 | 998 | 255/480/705 | 595 | 150 |
| 左下圆形人物 | -10 | 762 | 288 | 288 |
| 右侧手机/产品区 | 1015 | 205 | 620 | 875 |

坐标是对当前样片的等比近似。人物框转圆形时，直接动画同一个人物层的 `x/y/width/height/border-radius`，不要切换成另一段视频。

## 关键动画参数

- 全屏 -> 左竖框：`0.65-0.85 s`，`easeInOutCubic`。
- 每张步骤卡填字：`0.35-0.55 s`，`scale 0.25 -> 1.08 -> 1`。
- 左竖框 -> 圆形头像：`0.40-0.55 s`；手机晚 2-3 帧进入。
- 暗场：`0.15-0.25 s` 到 72% 黑。
- 三层大字：每层间隔 `0.45-0.70 s`，带 2-3 层方向残影。
- 返回真人：1 帧硬切。

## 文案槽位

```text
今天用一条视频讲清楚【主题】。
这是【产品/方法】的【一句定位】教程。
我会从【步骤1】开始，讲到【步骤2】，再带你做【步骤3】。
还会演示【设备/案例/成果】。
用【数量】个【实战场景】，让你【明确结果】。
我们开始。
```

## 必守规则

1. 人物每次缩小，都要同时放大一个更重要的信息对象。
2. 路线图先显示空卡，再随口播逐项填字。
3. 纸张课程图阶段，人物约占 30% 宽，不是角落小窗。
4. 产品进入后，人物才降级为约 15% 宽的左下圆形头像。
5. 强特效只绑定一个关键词；数字承诺只在开头最后 3 秒使用。
6. 抖音搜索、点赞、作者信息和返回键都是平台 UI，不进模板。

完整观测、逐秒证据和 45 秒后续特效见 `风格库3.MD` 与 `风格库3-逐秒索引.csv`。
