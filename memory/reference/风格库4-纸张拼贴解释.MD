# 历史子参考：纸张拼贴定格解释（Paper Collage Explainer）

> `MG-VOXSTAGE` 已接管风格库4主入口。本文件保留作历史子参考；除非用户明确点名 `paper-collage-explainer`，否则不要将其作为“风格库4”默认风格。

> 版本：2026-08-25
> 来源：用户提供的 `paper-collage-explainer-generator` Skill 文本
> 来源状态：规范移植，**没有参考视频实测**；本文中的时长、颜色和构图均为来源默认值或本地复刻建议，不是源工程参数。
> 兼容性：原 Skill 面向 MiniMax Hub；本文件把它整理成当前本地视频工作流可执行的视觉风格，不代表已经安装 Hub 工具或授权生成媒体。

## 0. 一句话风格

用平面大胆色场、黑白半色调照片剪影、彩色卡纸、暖奶油描边和柔和纸张阴影，把一句口播或一个抽象概念拆成 3-6 组可读的纸片对象，按“出现 -> 滑入/弹入 -> 轻弹 -> 压平 -> 停住 -> 锁定”的停格节奏组装成一个有前景、中景和后景的编辑部式拼贴画面。

它的重点是**具象隐喻 + 手工材质 + 可读停格动作**，不是慢推、漂浮、全局淡入或装饰性文字动画。

## 1. 适用边界

### 适合

- 把一条短口播、观点句、知识点或抽象主题转成视觉隐喻 B-roll。
- 需要连续多个短片段、但希望它们像同一套编辑部纸拼贴系列。
- 用纸片组装表达“打开、连接、泄露、归档、压缩、拆分、揭示、转化、碰撞”等动作。
- 需要保留或生成纸张滑动、弹入、压平、轻拍、摩擦和小纸张断裂声等拟音。
- 需要批量把不同句子转成独立片段，再按分镜顺序组合。

### 不适合

- 真人主导的产品广告或主持人口播主画面。
- 需要精确可编辑图层、时间线关键帧、透明抠图交付或严格 Logo 位置。
- 需要观众逐字阅读的 UI、代码、长提示词或品牌字标。
- 只要一段文字提示词、不需要生产计划与媒体制作的任务。

## 2. 来源默认值与本地工作流适配

| 项目 | 风格库4默认 | 本地工作流执行口径 |
|---|---|---|
| 画幅 | 16:9 横屏 | 用户另指定时服从当前项目画幅；未指定才用 16:9 |
| 单段时长 | 约 4 秒 | 以语义完整和最终画面可读为准，可延长；不强行压成 4 秒 |
| 视觉主材 | 高级编辑部纸张拼贴、半色调照片剪影 | 用已授权素材或批准的生成素材；不把参考样片当素材 |
| 默认音频 | 纸张拼贴 SFX | 保留原片中已有的拼贴 SFX；缺失时可规划生成/补录 |
| BGM | 默认不加 | 只有用户明确要求才加入 |
| 口播/旁白 | 默认不加 | 只有用户明确要求才写、合成或混入 |
| 字幕 | 默认不加 | 只有用户明确要求才制作；当前工作流字幕始终属于主画面 |
| 默认视频模型 | `MiniMax-H3` | 仅作为来源建议，不代表本机可用或已经安装 |
| 画面文字 | 不出现可读文字、数字、UI、Logo、水印 | 若脚本必须展示可复制文字，改用 `code-prompt-stage`，不要硬套拼贴图像生成 |

### 与当前五种画面状态的关系

- 拼贴片段是 `material-fullscreen` 的一种内容表现，成片中应优先铺满主画面。
- 若同时存在真人口播，真人沿当前项目的连续素材轨缩到安全角 PIP；不要重新起一段人物视频制造假连续。
- 拼贴段落之间的画面状态变化仍必须有语义匹配的转场；同一状态内只删除口误和卡顿时可干净跳切。
- 字幕不是拼贴纸片的一部分。用户批准字幕后，字幕放在主画面安全带，不能压住主要纸片、隐喻主体或真人 PIP。
- 拼贴中的“纸张组装”是段内主运动语言；不要与持续镜头推拉、粒子雨、复杂 Glitch 同时抢主位。

## 3. 视觉 DNA

### 3.1 材质与边缘

- 平面大胆色场，底纸有轻微纤维而不是完全数码平面。
- 黑白半色调摄影剪影作为主要结构，彩色卡纸只在确实能澄清层级的位置出现。
- 暖奶油色细描边、软物理阴影、轻微撕边、细小纤维和可见纸张接缝。
- 纸张应干净、精致、像手工编辑部道具；不要默认做成牛皮纸、发黄、污渍、重褶皱或旧报纸。
- 每个对象应能被理解为独立纸片组：背景、主体、辅助对象和前景层不要糊成一张不可分割的平面。

### 3.2 色彩角色

| 角色 | 建议方向 | 适合表达 |
|---|---|---|
| Burnt orange / red | 烧橙或红色 | 劳动、时间压力、紧迫、冲突 |
| Mustard yellow | 芥末黄 | 工具、警告、积累的错误、重点 |
| Ink green | 墨绿 | 认知、重置、判断、超现实平静 |
| Deep purple | 深紫 | 记忆、结构、神秘、梦境逻辑 |
| Teal | 蓝绿色 | 协作、执行、系统流动 |
| Rose red | 玫瑰红 | 荒诞、仪式、戏剧张力 |
| Warm cream | 暖奶油色 | 关键线、纸张高光、统一批次 |

使用规则：先确定一块与批次一致的主色场，再选 1-2 个强调色。不要每段都换底色，也不要把钴蓝当自动默认。全片的统一性主要来自半色调、纸张纹理、奶油描边、阴影和构图，而不是所有段落使用同一个色值。

### 3.3 构图与景深

- 默认横向编辑部构图，至少分出背景、主体中景和前景装饰三个层次。
- 每段只安排一个中心隐喻，关键对象有清楚的视觉层级和干净负空间。
- 默认 3-6 组大型可读纸片；宁可减少碎片，也不要把画面塞满。
- 需要横向叙事时，让纸片在左到右或前到后的方向上形成动作逻辑；不要随意旋转飞行。
- 画面中可以保留前景虚化纸片或大面积负空间，但不能遮挡隐喻主体。

### 3.4 文字禁区

- 生成的图像/视频默认不出现可读字母、数字、字幕、UI、Logo、水印或伪文字。
- 如果文字是观众必须复制或逐字阅读的内容，离开本风格，使用 `code-prompt-stage` / `document-typewriter-reveal`，并保留原文。
- 如果只是需要一个抽象“标签感”，用无字纸片、色带、印章形状表达，不伪造品牌或事实。

## 4. 概念拆解方法

每条句子或故事主题先提取以下字段，再决定纸片对象：

1. **核心含义**：观众看完应该理解什么。
2. **情绪**：平静、紧迫、讽刺、惊讶、荒诞、澄清、反思、神秘或玩味。
3. **动作动词**：打开、连接、泄露、归档、压缩、拆分、照亮、绑定、组装、揭示、掉落、追逐、转化、碰撞。
4. **视觉隐喻**：不用把原句写出来，而是找一个能承载关系的具体纸片场景。
5. **关键对象**：3-6 组大纸片，写清前/中/后景角色。
6. **声音落点**：滑、弹、压、拍、摩擦、折断中的哪一种动作需要拟音。

故事主题默认拆成 3-6 个简短 beat。相近 beat 可以复用材质和节奏，但必须在隐喻、物件、色场或声音重音上形成可辨差异。

## 5. 标准画面状态

### `paper-field`

干净的主色纸张场，只有少量纤维和空间层次。用于开头、段间呼吸和组装前的空场。

### `collage-assembly`

纸片按可读顺序逐组进入：背景结构 -> 主要隐喻 -> 次要对象 -> 前景点睛。每组做一次出现/滑入/弹入、轻弹、压平、停住，避免所有元素同时淡入。

### `collage-settled`

所有关系已经锁定，保持接近批准的最终静帧。阅读或理解阶段不做无意义的持续运镜，默认留 0.8-1.5 秒稳定画面。

### `collage-broll-with-pip`

拼贴是全屏主素材，真人在不遮挡主体的安全角固定 PIP。只在当前视频确实含真人口播时使用；PIP 位置由纸片负空间决定，不强制永远右下。

### `optional-audio-layer`

只描述已获批准的拼贴 SFX、BGM、旁白或字幕层。默认只有拼贴 SFX，其他三类均为可选附加层。

## 6. 停格运动语法

### 默认组装顺序

1. 从与批准静帧相同色调的干净纸张场开始，不从不匹配的牛皮纸或棕黄色底开始。
2. 背景结构以纸片滑入、弹入或压平的方式出现。
3. 角色、卡片或中心隐喻对象进入主位。
4. 次要对象逐个出现，加入轻弹、压平和短暂停顿。
5. 前景纸片或小道具完成层次，最终关系锁定。
6. 保持完成后的静帧感，给观众读懂隐喻的时间。

### 建议时间轴（约 4 秒）

| 段落 | 默认区间 | 画面动作 | 声音建议 |
|---|---:|---|---|
| 主色场 | 0.00-0.35s | 空纸场稳定出现，确认色调 | 轻纸面摩擦，可无声 |
| 背景组 | 0.35-1.00s | 1-2 组底层结构滑入/压平 | slide + press |
| 中心隐喻 | 1.00-1.90s | 主对象弹入、轻弹后锁定 | pop + soft tap |
| 次要对象 | 1.90-2.90s | 1-3 组错峰进入，逐项停住 | slide / rustle |
| 前景点睛 | 2.90-3.35s | 最后一组小物件压平 | tap / tiny snap |
| 稳定阅读 | 3.35-4.00s+ | 贴近批准静帧，停止运镜 | 只保留尾部纸张声 |

以上只是默认节奏；如果隐喻需要更多建立时间，应延长稳定段，不靠加快碎片进入来硬塞信息。

### 必须避免

- 快速旋转、无方向的纸片飞行、混乱碰撞。
- 全局淡入、平滑数字图层漂移、慢速通用推拉或镜头缩放。
- 生成新对象、场景切换、变形、持续滚动或复杂相机运动。
- 阅读时持续让背景运动，或把多个高能动作叠在同一拍。
- 为了“更丰富”增加不可解释的小纸片。

## 7. 声音规则

### 默认交付

**保留或生成拼贴 SFX；不默认加入 BGM、口播/旁白或字幕。**

- 视频模型生成了有用的纸张声时，后期默认保留原音轨。
- 缺少拟音时，可在方案中标记 slide、pop、press-flat tap、light rustle、tiny snap 的补录或生成位置。
- 只有用户明确要求才加入音乐、旁白/口播或字幕；追加层应与原有拼贴 SFX 混合，而不是无理由替换。
- 发现生成音频带有不需要的说话、音乐、假 UI 音或噪声时，应按目标移除、替换或重生成。

### 与口播视频合成

- 连续口播音轨保持连续；拼贴全屏时真人缩到安全角 PIP。
- 字幕若获批准，属于主合成层，避让纸片主体、关键负空间和真人 PIP。
- 不能把拼贴 SFX 默认当成 BGM，也不能因为是“解释视频”就自动补写旁白。

## 8. 两道审批门

### Gate 1：生产计划

生成任何静帧、视频或音频前，先写计划并等待确认。计划至少包括：

- 主题/原句、受众与使用场景（已知才写）。
- 画幅、段数、时长假设、情绪和节奏。
- 视觉风格总结与色场方向。
- 音频默认声明：保留/生成拼贴 SFX；BGM、口播和字幕不是默认项。
- 每段的核心含义、情绪、隐喻、3-6 个对象、颜色、组装顺序和拟音。
- 静默视觉 beat track；只有用户明确要求旁白时才写 voiceover 脚本。
- 分段故事板：标题、最终帧、运动、时长、SFX 和批次连续性。

用户只批准部分编号时，只推进被批准段落，其余保持待修改。

### Gate 2：静帧审核

Gate 1 批准后，先为每段生成/准备一张接近未来视频最终帧的静帧规格或静帧。展示静帧并等待确认后，才进入视频生成或动画制作。

静帧必须检查：主色场一致、3-6 组对象清楚、前中后景可辨、中心隐喻明确、纸张边缘与阴影精致、无伪文字/UI/Logo/水印、留有可读负空间。

### 当前工作流授权边界

完成风格方案不等于批准素材采集、制作小样、启动 Remotion 或最终渲染。任何实际视频项目仍须在该项目 `04-动效与包装/` 先写四份规划文档，并遵守 `workflow.json` 的阶段确认。

## 9. 质量检查

- 不看文字也能理解隐喻或故事 beat。
- 画面默认 16:9，主色场干净，前景/中景/背景层次可读。
- 纸片组数量控制在可辨范围，中心对象没有被碎片淹没。
- 片段从与批准静帧一致的色场开始。
- 运动确实读成“组装停格”，而不是整体淡入或平滑数字动画。
- 每组纸片有出现顺序、轻弹/压平/停住和锁定；不是同时飞入。
- 默认只有拼贴 SFX；没有未经确认的 BGM、旁白、对白或字幕。
- 纸张有轻微纤维、撕边和接缝，但没有脏旧、棕黄、牛皮纸或过度褶皱。
- 批次之间共享纸张材质、描边、阴影、构图节奏和 SFX cadence。
- 最终帧接近已批准静帧，没有新对象或构图大漂移。
- 没有可读伪文字、品牌 Logo、水印、UI 或不必要的相机运动。

## 10. 可复用交付字段

每个片段交付时记录：

- 原句/故事 beat 与视觉隐喻的一句话对应关系。
- 计划、静帧和视频文件路径（若已进入相应阶段）。
- 画幅、时长、主色场、对象组和组装顺序。
- 拼贴 SFX 是否保留/生成；是否有用户明确批准的 BGM、旁白或字幕。
- 质量检查结论与可接受的小幅细节漂移。

## 11. 失败处理与返工规则

- 计划里未经用户请求出现 BGM、口播/旁白或字幕时，删掉默认添加，改列为可选项。
- 隐喻过于直白或变成文字说明时，退回 Gate 1，改成由对象关系承载含义。
- 静帧出现伪文字、假 UI、Logo 或水印时，先重做静帧，不要只靠视频提示词补救。
- 画面太拥挤时，减少纸片组、恢复负空间，不用缩小主体来塞更多对象。
- 视频看不出组装过程时，减少对象数量并把“出现 -> 轻弹 -> 压平 -> 停住 -> 锁定”写得更明确。
- 运动像平滑数字图层时，重写为纸片的错峰停格动作，去掉连续漂移、镜头推拉和无方向旋转。
- 纸张太平时，补充细撕边、纤维、分层接缝和软阴影；纸张太脏或太棕时，移除牛皮纸、发黄、污渍和重褶皱。
- 开头色场与批准静帧冲突时，从批准静帧的主色重新开始；最终帧漂移过大时，强化“批准静帧就是完成构图”的约束。
- 音频缺少拼贴 SFX 而画面合格时，先确认保留现状、重生成拟音，还是后期补/对齐 SFX；出现不需要的音乐或说话时，移除或重生成。
- 如果项目真正需要精确图层控制，停止套用本风格，改推荐可编辑的分层动画或常规剪辑工程。
