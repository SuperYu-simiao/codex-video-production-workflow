## 一句话风格

这是一个“轻科技知识口播包装”风格：真人口播保持在右侧或中右区域，背景是柔和的办公室/空间场景；左侧叠加奶白色信息卡、工具列表、截图标注、手写数字和文件标签，让观众感觉像在看一个 AI 工作流教学，而不是纯讲解。

## 画面基调

- 主画面：真实口播 + 虚化/半透明背景，人物清晰，背景偏暖、干净、低对比。
- 包装气质：轻量、教学感、产品说明感，不是赛博朋克，也不是强炫技。
- 视觉关键词：奶白卡片、橙色标题、黄色字幕强调、红框标注、鼠标光圈、文件标签、工具 logo。
- 画面节奏：每 5-10 秒出现一次信息包装；每个包装服务一句话，不要一直堆满屏。
- 适合内容：AI 工具教程、工作流拆解、插件安装、剪辑/自动化流程说明、案例复盘。

## 画幅与构图

- 参考视频尺寸：`1822x1024`，接近 16:9 横屏，60fps。
- 推荐输出：`1920x1080` 或保持原素材横屏比例。
- 人物位置：
  - 常规口播：人物在画面中间偏右，给左侧留包装空间。
  - 全屏截图讲解：截图占 80%-100% 画面，人物可缩成右下角 PIP。
  - 重点结论：人物回到中间，左侧只放一组大字或少量卡片。
- 安全区：
  - 底部字幕占下方 10%-16%，不要让卡片挡字幕。
  - 左侧卡片最好在画面左 5%-45% 区域内。
  - 人脸区域保持干净，避免卡片盖住眼睛、嘴和手势。

## 色彩

主色建议：

- 背景奶白：`#F7F2E8`
- 卡片白：`#FFFFFF`
- 深文字：`#2B241D`
- 次级文字：`#9A8F80`
- 橙色强调：`#D9733A`
- 暖黄字幕强调：`#F5D12A`
- 红框标注：`#B6202B`
- 深棕标签底：`#3A251B`
- 半透明遮罩：`rgba(247, 242, 232, 0.68)`

使用规则：

- 大面积背景用奶白/暖白，不用纯黑科技风。
- 强调词用橙色或黄色，不要同时出现太多颜色。
- 红色只用于截图标注框，不用于普通标题。
- 文件标签和状态标签可以用深棕底 + 白字，形成局部视觉重心。

## 字体与文字风格

- 中文标题：偏宋体/衬线感，或细长优雅字体，适合“教程、方案、清单”的感觉。
- 英文/工具名：无衬线，偏产品 UI 字体。
- 字幕：
  - 白字 + 黑色粗描边。
  - 关键词改黄，保持同一行内强调。
  - 字幕居底，字重较粗，风格接近短视频口播字幕。
- 屏幕文字不要太多；卡片里只写“让观众扫一眼就懂”的短句。

## 重点：开头动效复刻

如果只复刻这个风格里最重要的开头，优先做这一套，不要先做后面的文档页和截图页。

### 开头视觉结构

- 真人口播是主体，人物在中右区域，手指向左上方卡片区。
- 背景是明亮办公室空间，不做纯色背景；背景略柔和，人物清晰。
- 左侧和人物背后悬浮 4-6 张白色工具卡片，形成轻微 3D 景深。
- 卡片不是平铺 UI，而是像空间里的标签牌：有远近、前后遮挡、大小差异。
- 画面中央偏右有一个大鼠标指针，像是在操作这些卡片。
- 底部保留粗描边口播字幕，关键词可用黄色。

### 开头卡片内容

建议卡片内容按这类结构设计：

- `HeyGen HyperFrames`
- `Remotion render`
- `Codex agent`
- `video-use`
- `AI 动效`
- 小胶囊标签：`3D 旋转`、`工具链`、`一键生成`

卡片样式：

- 白色圆角矩形，圆角 12-18px。
- 轻微阴影，不要重投影。
- 卡片内 logo/小图标在左，名称在右或下方。
- 英文工具名用黑色/深灰；小标签用橙色或浅灰。
- 卡片可以略微旋转 `-3°` 到 `3°`，但不要歪得夸张。

### 开头动效时间线

适合 6-8 秒开场：

| 时间 | 画面 | 动效 |
|---|---|---|
| 0.0-0.4s | 人物已经在画面中，左侧卡片半透明可见 | 背景轻微虚化，卡片 `opacity 0 -> 1`，`scale 0.96 -> 1` |
| 0.4-1.2s | 3-4 张工具卡片浮在左侧和人物背后 | 卡片错峰出现，每张延迟 0.12-0.18s |
| 1.2-3.5s | 人物手指指向卡片 | 卡片做极轻悬浮：上下 4-8px，左右 2-5px |
| 2.0-4.0s | 大鼠标指针从中间偏右掠过 | 指针移动到卡片附近，可加一次轻微点击光圈 |
| 4.5-6.8s | 卡片逐渐横向重组到画面下方/中下方 | 卡片滑动、缩小、排成一排，给后续讲解让位 |
| 6.8-8.0s | 进入下一段工具解释 | 卡片淡出或保留 3-4 张小卡作为背景提示 |

### 运动参数

- 入场：`opacity 0 -> 1`，`scale 0.94 -> 1`，`y +18 -> 0`。
- 缓动：`easeOutCubic`，不要线性。
- 卡片错峰：每张相差 `0.12-0.18s`。
- 悬浮：幅度小，周期 `2.5-3.2s`，不同卡片相位错开。
- 鼠标指针：速度慢，像真实屏幕操作，不要飞来飞去。
- 点击光圈：黄色半透明圆，`scale 0.6 -> 1.4`，`opacity 0.35 -> 0`，时长 `0.35s`。
- 退出/重组：卡片向下方或左侧聚合，`scale 1 -> 0.82`，时长 `0.5-0.8s`。

### 空间层级

卡片层级建议：

1. 背景办公室视频。
2. 轻微暖白遮罩，透明度 `0.08-0.18`，让卡片更清楚。
3. 后景小卡片：`scale 0.78-0.9`，模糊 0-1px，透明度 0.75-0.9。
4. 前景主卡片：`scale 1.0`，透明度 1，阴影更明显。
5. 鼠标指针和点击光圈。
6. 底部字幕。

### 开头不要做什么

- 不要做大量粒子、光线、赛博网格。
- 不要让卡片遮住人物脸。
- 不要每张卡片都强烈弹跳，参考片是轻悬浮。
- 不要把开头做成纯 UI 页面，必须保留真人口播现场感。
- 不要一开始就全屏截图；开头重点是“工具卡片围绕真人”的空间包装。

### 1. 漂浮工具卡片

用途：开场展示工具、插件、关键词。

画面特征：

- 多张白色圆角卡片悬浮在人物左侧或身后。
- 卡片之间有前后错位，制造轻微景深。
- 卡片内容通常是 logo + 工具名，例如 `HyperFrames`、`Remotion`、`Codex`、`video-use`。
- 可加一个小胶囊标签，例如 `3D 旋转`。

动效：

- 进入：从左侧或后方轻微位移进场，伴随 `opacity 0 -> 1` 和 `scale 0.96 -> 1`。
- 停留：轻微悬浮，位移 4-10px，周期 2-3 秒。
- 退出：淡出或向左/向后轻移。
- 节奏：每张卡片错开 0.12-0.2 秒出现。

### 2. 左侧奶白工具清单面板

用途：展示工具列表、步骤列表、目录。

画面特征：

- 左半屏出现一块奶白色面板，右侧保留人物。
- 顶部有小 logo 和小标题，如 `工具箱 + TOOLS`。
- 条目是横向浅色卡片：icon + 名称。
- 条目之间有细分隔线。

动效：

- 面板从左侧滑入，或先出现半透明遮罩再展开。
- 条目逐项出现：每项间隔 0.12-0.18 秒。
- 当前重点条目可以轻微放大或加深文字。

### 3. 截图/网页全屏讲解

用途：演示安装、网页、代码、文档。

画面特征：

- 截图占据几乎整个屏幕，背景变成白色网页/文档。
- 可保留一个小 PIP 人像在右下角，或者直接全屏截图。
- 鼠标指针和黄色光圈用于引导视线。

动效：

- 截图可以直接切入，也可以从 96% 放大到 100%。
- 鼠标光圈停留在重点位置 0.5-1 秒。
- 讲到具体区域时，用红框锁定。

### 4. 红框区域强调

用途：强调按钮、路径、API key 步骤、关键文本。

画面特征：

- 红色矩形描边，线宽 3-5px。
- 框内内容可以配合蓝色文本选中效果。
- 红框通常在白色截图上出现，视觉对比强。

动效：

- 红框用“描边绘制”或快速缩放出现。
- 出现时间 0.2-0.35 秒。
- 停留 1.5-3 秒。
- 可配合鼠标黄色光圈轻点一下。

### 5. 手写数字/时间对比

用途：展示效率变化、前后对比、时间压缩。

画面特征：

- 左侧半透明口播背景上出现手写感数字。
- 示例：`4分 -> 3分`、`7-2h -> 15分钟`、`<1分钟`。
- 数字颜色偏橙红，正文黑/深棕。
- 旁边可加小字标签，如 `时长缩短`、`效率提升`。

动效：

- 数字像手写一样逐笔出现，或用轻微擦写 reveal。
- 箭头从左到右出现。
- 新数字出现时轻微弹一下，突出结果。

### 6. 参考清单/动效清单 collage

用途：展示素材库、参考风格库、动效收藏。

画面特征：

- 左侧一张大白色画布。
- 里面堆叠多张小截图、卡片、封面图，有轻微旋转角度。
- 标题用橙色中文，比如 `喜欢的动效清单`。
- 画面像 Notion/白板/素材墙。

动效：

- 小图卡按顺序飞入，位置有轻微错落。
- 最后整体稳定成一个 collage。
- 之后可切换成表格/清单文档，表达“整理成方法论”。

### 7. 文件路径/素材标签

用途：说明给 AI 的素材命名、文件位置、输入文件。

画面特征：

- 深棕色圆角标签，左侧有小 icon。
- 示例：`goal1.mp4`、`/材料/录屏/`。
- 标签悬浮在人物左侧中部。
- 文字颜色白色或浅黄。

动效：

- 标签从左侧滑入，带轻微弹性。
- icon 先出现，文字后出现。
- 重点词可用黄色高亮。

### 8. 包装方案气泡/流程卡

用途：说明从“好视频”到“包装方案”的转换。

画面特征：

- 两三个白色或橙色胶囊卡片。
- 卡片之间用橙色箭头连接。
- 核心词放在橙色实心块里，例如 `包装方案`。

动效：

- 左卡先出现，箭头绘制，右卡再出现。
- 核心橙色卡片出现时做小幅 scale bounce。
- 适合放在人物左侧，不遮挡脸。

### 9. 执行状态卡 / 正在生成卡

用途：展示 Codex、HyperFrames、Remotion 正在处理。

画面特征：

- 白色圆角状态卡，带 logo。
- 文案类似：`正在添加 HyperFrames by HeyGen...`、`正在添加 Remotion...`。
- 可以叠在网页截图上，也可以放左侧中部。
- 有时配合右下角 PIP 人像。

动效：

- 卡片淡入 + 微微上浮。
- 状态点或边框可以轻微闪烁。
- 多张卡片错开出现，表达并行处理。

### 10. 右下角 PIP 人像

用途：全屏截图或文档讲解时保留讲解者存在感。

画面特征：

- 人像小窗放右下角，约占画面宽度 18%-24%。
- 圆角 10-16px，带轻微阴影。
- 背景是截图/网页/文档。

动效：

- 从右下角轻微滑入。
- 切回口播时 PIP 放大回主画面或直接切回。

### 11. 卡片墙轮播 -> 单卡聚焦放大

独立动效说明：`/Users/yusimiao/Desktop/AI内容工厂公开版 2/视频剪辑/动效库/卡片墙轮播到单卡聚焦放大/动效说明.md`

用途：开场快速展示多个案例、工具、功能或成片画面，然后把观众注意力集中到其中一张。特别适合“你现在看到的这些”、“先看几个效果”、“今天重点讲这个”之类的口播开头。

画面特征：

- 背景是一块统一的深色舞台；参考片用深紫，在本风格中也可换成深棕或暖黑。
- 画面中同时排布 7-10 张白色大圆角卡片，分成约 3 排，中间留出稳定的深色缝隙。
- 卡片可以是网页截图、工具界面、动效成片或功能标题页；每张卡片内容不同，但圆角、留白和色彩体系统一。
- 边缘卡片只显示一部分，让观众感觉画面外仍有内容，增强轮播和延展感。
- 最终选中的主卡通常在中间一排；它不换图，而是作为同一个对象从卡片墙中脱离并放大，产生连续的 match zoom 感。

参考片开头时间结构：

> 下表只用于理解运动节奏。“单卡 -> 卡片墙 -> 轮播 -> 主卡放大 -> 向上推入”是一条连续动效，保存和调用时不得拆分成多个素材。

| 时间 | 画面状态 | 运动 |
|---|---|---|
| `0.00-2.30s` | 一张主页卡接近全屏 | 先让观众看清主视觉，运动很轻 |
| `2.32-2.70s` | 从单卡切换为多卡片墙 | 快速 zoom-out，一次露出多个页面 |
| `2.70-4.35s` | 3 排卡片墙占满画面 | 整组做极慢的横向漂移/轮播，边缘卡片保持裁切 |
| `4.35-4.95s` | 其他卡片向外退场，中间主卡被选中 | 主卡移到中心并连续放大，其他卡片滑向边缘，不用简单交叉淡化 |
| `4.95-6.85s` | 主卡成为中心大画面 | 停留 1.5-2 秒，可加极轻的慢推近 |
| `6.85-7.30s` | 主卡内容进入下一块 | 整页向上推，新卡片从下方接管画面 |

复刻参数建议：

- 卡片墙缩放可以从 `scale 1.0` 到 `0.34-0.42`；单卡聚焦阶段再从缩略状态放大到画面宽度的 `90%-96%`。
- 卡片间隙建议占画面宽度的 `1%-1.8%`，圆角为 `18-32px`（以 `1920x1080` 为基准）。
- 轮播漂移要慢，1.5-2 秒只移动画面宽度的 `2%-5%`；重点是展示数量，不是快速刷屏。
- 聚焦转场建议 `0.5-0.7s`，用 `easeOutCubic` 或 `cubic-bezier(0.16, 1, 0.3, 1)`，让放大快速起动、柔和落位。
- 选中的卡片必须保持视觉连续：最好移动同一个 HTML/Remotion 元素，或使用同一张图做对齐的 match cut，不要在放大中途更换截图。
- 转场期间可加轻微运动模糊和一个柔和 whoosh；卡片落位时加很轻的 soft hit，不要用重爆炸音。
- 主卡放大后至少留出 `1.2s` 稳定阅读时间，不要立即切走。

在当前口播视频中的用法：

- 可用在开头“你现在看到的这些，这些，还有这些”：卡片墙里同时展示漂浮工具卡、字幕效果、截图红框、时间对比和成片预览。
- 说到“都是 Codex 搭配 HyperFrames 直接生成的”时，选中包含 `Codex + HyperFrames` 的主卡放大，与口播结论同步落位。
- 只复用“多卡 -> 单卡”的运动结构；卡片颜色仍按本风格的奶白、橙色、暖黄和深棕执行，不必照搬参考片的紫色。

可直接使用的提示词：
