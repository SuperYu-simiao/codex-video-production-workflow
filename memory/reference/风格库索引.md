## 选择规则

1. 先按内容任务选风格，再按口播语义选具体镜头；不要为了填满画面强行套风格。
2. 需要观众读清真实网页、代码、提示词或复杂表格时，优先使用当前工作流的 `material-fullscreen` / `code-prompt-stage`，不要把可读信息压成报纸碎片。
3. 风格库4的标题、数据、日期、人物关系、地图路线和文件编号必须来自可核验资料；匿名遮眼条只用于真实保护身份需要。
4. 风格库4的镜头、景深、动态和构图参数是用户提供的创作规范与本地实施建议，不是参考视频或生成模型实测。
5. 使用任何风格都要遵守 `docs/00-先读我.md`、`workflow.json`、`effects.json`、`特效与切屏规范.md` 和当前项目阶段门槛。
6. 风格库负责色彩、空间、材质、构图与叙事气质；Shotcraft 负责经校验的运动语法；Remotion 只负责按导演时间线合成。不要只记住效果名而丢掉风格底盘和已确认编排。
