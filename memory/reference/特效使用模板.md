# 特效使用模板：逐字稿语义 / 素材 / 场景切换 → 特效自动选型

> 用途：进入包装阶段后，Agent 依据**逐字稿语义、素材切入点、场景切换**，直接从 Video Shotcraft 仓库自动选特效，不再逐句向用户要"这句话配哪个特效"。第7期《workbuddy 自动整理知识库》里逐句确认过的用法是已验证基线（优先用）；未验证的按 Gallery `library.json` 每张卡的 `use`/`intention` 字段扩展。特效名相同≠观感相同：选中卡后必须读完整镜头卡 + 准确 demo TSX，不能凭卡名手写近似。

## 0. 选型总流程（每期包装固定走一遍）

1. 逐字稿按**语义句群**拆节点（约 2–3 句一个节点；节点边界 = 语义落点，不是固定时长）。
2. 每个节点先判「逐字稿语义」（§1）→ 定**主动效**（一个节点一个主动效）。
3. 再判「素材/画面类型」（§2）→ 定**人物状态和布局**。
4. 相邻节点之间判「场景切换」（§3）→ 定**转场**。
5. 过「硬规则」（§4）自查。
6. 落到当前项目 `04-动效与包装/特效映射.json`：真实口播时间、卡名、style-key、转场、稳定阅读时长。

## 1. 逐字稿语义 → 特效（主决策）

### 1.1 结构语义：句子在篇章里扮演什么角色

| 语义类型 | 逐字稿触发特征 | 默认特效（card · style-key） | 画面怎么动 / 怎么插 |
|---|---|---|---|
| 章节 / 小标题 | "接下来""先看""第二步大方向""最后总结"等进入新大段 | `aurora-bloom-bg-flip` | 旧标题 blur-out → 留空档 → 新标题 blur-in 后落定；约 0.36s 翻色，翻完停住留阅读时间 |
| 工具 / Skill / 产品名首次出现 | 专有名词第一次被念出 | `assemble-then-type-flyin` | 左框"骨架→标题→文字"组装、工具名逐字 3D 落位；右框放该工具 landing page / GitHub 首页 / Logo 截图，比左框延迟约 0.3s；落定停止运镜 |
| 工具 / Skill / 产品名重复出现 | 前面已完整组装过 | 同一工具卡**短召回** | 复用已组装卡片，0.4–0.8s 短飞入/高亮，不重搭骨架 |
| 步骤枚举 | "第一步/第二步""一共三步""下载→理解→整理" | `autolayout-gap-dial` | 步骤块数 = 逐字稿真实步数；数字、测量线、块位置由同一个 gap 参数同帧驱动，最后收成进度轨 |
| 结论 / 主张句 | "这就是""最便捷""唯一""核心就一句" | `spotlight-hero-card`（单一主角卡）/ `logo-shrink-wordmark-lockup`（有真实商标字标时） | 主角卡或字标落定，hold ≥1s |
| 停顿 / 悬念句后的转场 | 设问、留白、翻篇前 | `card-flock-tumble` + BGM | 真正暂停源视频轨、插入独立桥接；桥接结束从**同一源帧**恢复；BGM 不压人声 |

### 1.2 内容语义：句子在讲什么（按"讲的内容"选特效）

| 逐字稿在讲的内容 | 默认特效（card · style-key） | 说明 |
|---|---|---|
| AI / agent 先给结论、再逐条补证据、最后完成 | `ai-stream-response` | 结论摘要先落，证据行带状态图标逐条汇入，完成态收束 |
| 里程碑 / 成绩 / 用户数 / 下载量等"值得庆祝"的数字 | `counter-confetti` | 数字滚动 + 彩带；全屏级王牌指标用 `odometer-digit-roll` |
| 实时数据 / 波形 / 增长 | `chart-live-moves · oscilloscope-stream` | 讲"实时性""每个数字是一个人" |
| 用前 vs 用后 / 增强 / 优化前后对比 | `before-after-slider-scrub` | 一镜讲清效果对比；二选一/模式切换用 `segmented-thumb-hero` |
| 功能→成果 成对叙事（逐张翻出指标/结论） | `card-flip-reveal` | 元素级转场，一排卡逐张翻面 |
| 多源整合 / 数据汇聚 / 统一接入 | `bezier-source-converge-merge` | 多来源线条汇聚到一个入口 |
| 搜索 / 筛选 / 输入关键词得到结果 | `type-and-filter` | 操作叙事段 |
| 语音输入 / 听写 / 对 AI 说话 | `glass-pill-dictation-typing` | 语音输入框登场；无 UI 但需持续活性用 `voice-waveform-live` |
| 发送 / 邀请 / 分享 / 交接 | `paper-plane-messenger` | 纸飞机连接两个场景/人物 |
| 你与 AI 对话 / 多人协作 / 交接 | `collab-cursor-moves · dialogue-duet` | 双方对话、靠近、交接；再接 `canvas-materialize-moves · panel-to-canvas` 把结果落画布 |
| 命令面板 / 快捷键 / 一个输入框搞定一切 | `command-palette-summon` | 效率型产品的标志性登场 |
| 代码 / 配置 / 提示词 / 可复制文本 | `document-typewriter-reveal`（长文逐页）/ `typing-code-block`（就几行代码） | 逐字保留原文，字幕不压正文 |
| 文档 / 报告 / 笔记被 AI 读取、标注、拆解 | `scanline-annotate-focus` | "AI 正在读你的内容"的分析镜头 |
| 上传 → 解析 → 校验 过程 | `scan-bracket-sweep` | "正在解析/校验"的过程镜头 |
| 页面/海报自己长出来 / 从骨架到成稿 | `assemble-then-type-flyin` 或 `scanline-assemble-flyin` | 两段式：先立骨架再填文字 |
| 生成结果落到画布 / 已有内容换形态 | `canvas-materialize-moves · panel-to-canvas` | 面板/列表迁移到开放画布 |
| 标签 / 分类 / 关键词 | `hashtag-to-pill-materialize` | 输入 → 变成 UI 实体 → 归位 |
| 深色模式 / 主题切换 / 同一 UI 变色 | `theme-switch-moves · theme-sweep-toggle` | 眼前变色而非切新场景 |

### 1.3 工具 / 能力介绍组合（第7期验证的固定套）

口播逐个介绍工具/Skill 时，**每个工具段**固定用这套组合，不再逐句问：

1. 段首转场：`bubble-swarm-takeover`（上一个工具的画面被气泡群吞掉，露出新工具）。
2. 工具名首次出现：`assemble-then-type-flyin`（右框放真实官网/GitHub/Logo 截图）。
3. 逐行详细介绍：`ai-stream-response`（一行一行流式写出）。
4. 辅助演示特效，按该工具的具体内容在下面选 1 个（第7期用了这些）：
   - 里程碑/数字 → `counter-confetti`
   - 循环展示清单/作品 → `carousel-3d`
   - 实时波形 → `chart-live-moves · oscilloscope-stream`
   - 列表/面板迁到画布 → `canvas-materialize-moves · panel-to-canvas`
   - 命令/快捷键 → `command-palette-summon`
   - 步骤 → `autolayout-gap-dial`
5. 基础工具总述句（"接下来讲基础工具"这类一句带过多个工具）：`avatar-grid-radial-build-colorize`（图标网格径向展开上色）。

## 2. 素材 / 画面类型 → 呈现规则

按节点要展示的**素材切入点**，定人物状态和布局：

| 素材/画面类型 | 主画面 | 人物状态 | 说明 |
|---|---|---|---|
| 口播直接叙述、观点、情绪、开头结尾 | 真人口播全屏 | `P0` 全屏，保留胸口手势 | 默认起始状态 |
| 标题/章节/结论舞台 | 黑灰科技网格 + 标题动效 | `P1-R` 右侧竖屏小窗（宽约 27%）或右下小窗 | 标题在主画面，真人退角落 |
| 真实网页/录屏/截图/文档证据 | 素材铺满全屏，关键 UI 可读 | `P2` 1:1 正方形小窗（约 220×220），右下/左上 | 素材优先全屏，真人退安全角 |
| 可复制的代码/提示词/命令 | 大尺寸代码框，逐字保留原文 | 右侧安全区小窗，不挤正文 | `code-prompt-stage` |
| 密集阅读/章节门/概念特效/品牌桥接 | 全屏内容 | `P3` 隐藏人物，源音频连续 | 结束沿进入轨迹召回人物 |

**人物小窗硬规则（第7期用户原话："这一点是必须的"）**：1:1 正方形小窗必须按**人脸焦点居中**裁切，不是几何对称裁切；实现时保留源片全高，水平按 `50 - focalX × 16/9` 百分比平移，把脸落到正方形中心。小窗位置由 UI 空白区决定，不强制永远右下。

## 3. 场景切换 → 转场选型

两段画面之间的接缝，按"前后两镜的关系"选转场：

| 前后关系 / 场景切换类型 | 默认转场（card · style-key） | 说明 |
|---|---|---|
| 进入新章节 / 大段落翻篇 | `aurora-bloom-bg-flip` | 章节门统一用这个 |
| 章节级换景且品牌世界有实体装饰物（气泡/花瓣/图标可换皮） | `bubble-swarm-takeover` | 工具段之间默认用这个 |
| 能量高潮段 / 多卡片收束成一句话 | `card-flock-tumble` | 霓虹暗场调性 |
| 前后两镜有图形亲缘（进度条→卡框、下划线→图表轴） | `line-carry-transition` | 招牌图形接力转场 |
| 前后两镜存在元素/容器级空间关系 | `transition-travel · shared-element-morph` | 共享元素变形 |
| 功能→成果成对（一排卡逐张翻出结论） | `card-flip-reveal` | 元素级转场 |
| 发送/邀请/分享连接两个场景 | `paper-plane-messenger` | 动作即转场 |
| 普通接缝，两页都不动、一条边界扫过 | `wipe-transitions · mask-wipe` / `blinds-slice` | 通用安全转场，哪儿都能用 |
| 同主题快速切换 / 返回真人 / 短促结束 | `shot-transitions · flash-cut` | 短促强调 |
| 多张截图/多阶段/总览切单项 | `mosaic-reframe` | 同一批内容多种看法 |
| 章节或空间层级切换 | `cube-navigation` | 逐面导航 |
| 恢复口播（暂停桥接结束） | 桥接边框释放 | 从同一源帧继续，后续轨道统一补偿 |

**核心规则**：画面状态变化必须有转场；同一状态内删除口误/卡顿才允许干净跳切。转场要在句子语义落点开始，不是随意卡句中。

## 4. 硬规则（第7期验证，选型后必须自查）

1. **一个镜头一个主动效**：一种动画手法（飞入/堆叠/翻页）全片只当一次主角；重复镜头、重复 tagline 一律删。
2. **高能动作后必须呼吸**：关键信息落定后 hold ≥1s，批量动效收尾留 0.5s 静止；真实网页/文档进入阅读态后停止运镜。
3. **时间码来自真实口播**：逐字稿比例估时只用于规划；先做词级/句级对齐真实音频，再触发动效。
4. **暂停必须真拆源轨**：插入桥接时停住源视频和源音，桥接结束从同一源帧恢复，后续轨道统一补偿；"静音+盖定格图"不算暂停。
5. **导演备注不进观众画面**：只写进分镜文件；观众画面只显示逐字稿或批准素材。
6. **隐私脱敏**：录屏/截图去掉真实用户名、任务名、本机路径、密钥、余额；工具身份用公开官网/GitHub/Logo；手机端消息用标注的合成演示界面。
7. **特效名相同≠观感相同**：读完整镜头卡 + 准确 demo TSX，继承缓动、时值、纵深、运动模糊和布局，再替换本期内容；卡上标注的"已知坑/命门"参数不得降档。
8. **字幕属主画面**：绝不写进真人小窗；右下有小窗时字幕放主画面左侧约 68% 安全区，素材底部有重要 UI 则上移。
9. **同一特效不连续重复**：按语义选，不按固定时间间隔堆效果。
10. **高清源评审**：给用户看的小样直接读原始高清素材；低清代理只用于内部排错。

## 5. 选型自查清单（每期包装提交前过一遍）

- [ ] 逐字稿已按语义句群拆节点，节点边界都在句子语义落点。
- [ ] 每个节点只有一个主动效，且都能对应到 §1 的某一行语义。
- [ ] 工具/能力介绍段用 §1.3 固定套，没有漏"工具名→右框真实截图"。
- [ ] 每个画面类型都落到 §2 的某一行人物状态，正方形小窗按人脸焦点居中。
- [ ] 每处接缝都落到 §3 的某一行转场，没有生硬跳切。
- [ ] 高能动作后都留了稳定阅读时间。
- [ ] 特效映射.json 写入了真实口播时间、卡名、style-key、转场、稳定阅读时长。
- [ ] 选中的每张卡都读完了镜头卡全文 + 准确 demo TSX。
