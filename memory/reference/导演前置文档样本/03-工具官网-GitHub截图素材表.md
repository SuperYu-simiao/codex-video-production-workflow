## 截图统一规格

- 先采 2x 尺寸静态截图，至少 1920px 宽；保留完整浏览器内容区，不带收藏栏、扩展图标、通知或个人头像。
- 右框按 `16:10` 或页面原生比例 contain 展示，不为铺满而裁掉产品名、导航或主视觉。
- 每张截图冻结后做一次可读性检查；正文不要求逐字可读，但品牌名、仓库名和首页主标题必须清楚。
- logo 只能使用官方公开资产或官网页面内可见标识，不从搜索结果页或第三方素材站截取。
- 在正式采集前记录 URL、采集日期和公开来源；如页面改版，优先保证品牌身份与仓库名称，而不是强行复现当前计划截图。
