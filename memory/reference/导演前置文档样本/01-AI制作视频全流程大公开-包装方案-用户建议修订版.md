# 《AI制作视频全流程大公开》包装方案（用户建议修订版）

## 当前结论与时间基准

- 原片：219.4 秒，1920x1080，25fps，单一固定机位的 AI 数字人口播。
- 当前只有用户提供的逐字稿，没有词级时间戳。下列片源时间误差预计约 1-3 秒，正式制作前必须按原音做词级校准。
- 在“它到底是怎么做出来的？”后冻结人物尾帧并插入完整 `card-flock-tumble`，独立占用约 4.5 秒；若不再增删内容，包装母版预计约 223.9 秒。
- 插入点之前：母版时间 = 片源时间。插入点之后：母版时间约为片源时间 + 4.5 秒。录屏素材一律按“对应原句”匹配，不按母版绝对时间硬卡。
- 初始阶段只修订导演方案与素材需求；用户随后单独授权制作开头小样。现已生成 30 秒 720p 审核版。用户已授权修改开头工程，但明确要求先不重新渲染；整片与最终渲染仍未授权。

## 创意方向

一句话：把这条片做成一份“可验证的 AI 视频生产控制台”。人物负责可信叙述，真实录屏负责过程证据，Shotcraft 负责开场吸引力、工具身份与六步结构。

- 基础色：石墨黑 `#0B0D10`、冷白 `#F4F6F8`、界面灰 `#262B31`。
- 主强调色：沿用原片冷蓝 `#3A8DFF`；`aurora-bloom-bg-flip` 的紫橙极光降低饱和度，作为章节翻页信号。
- 第二强调色：琥珀 `#F2B35B`，仅用于“确认、批准、关键结论”；完成态少量使用绿 `#8FCB78`。
- 字体：中文使用苹方/思源黑体方向；工具名、命令和状态使用 SF Mono/等宽体。
- 真人：无素材时全屏；录屏、截图或信息面板全屏时，人物平滑缩到安全角 24%-26% 宽的 16:9 小窗。关键 UI 与小窗冲突时换角或暂时隐藏。
- 字幕：每行约 8-16 个汉字，最多两行，始终属于主画面；避让人物小窗和关键 UI。

### 开场合成层级

`neon-triple-marquee` 不能直接盖在扁平 MP4 上。制作时固定使用以下层级：

1. 原片背景或经修补的干净背景。
2. 透明版 `neon-triple-marquee`。
3. 从原片分离出的数字人人物前景遮罩。
4. `gradient-word-sweep`、工具卡、字幕等前景信息。

人物遮罩边缘要检查头发、肩部和手势；遮罩失败时退化为人物旁侧透明跑马灯，不能让文字穿过脸部。

## 六步章节与正文分镜

所有“小标题转场”统一使用 `aurora-bloom-bg-flip`，共六次。每次在“第 N 步”前约 0.8-1.0 秒开始极光酝酿，`第 N 步` 发音点触发约 0.36 秒的快速底色翻转，旧标题 blur-out，留短空档后新标题 blur-in。单次适配总长约 2.4-3.0 秒，不把原版 5.2 秒完整节奏重复六遍。

## 工具名统一规则

`assemble-then-type-flyin` 作为工具身份系统使用，而不是每次都重播完整 5.2 秒 demo：

- 每个工具第一次独立出现：先组装无字骨架，再让左侧工具名逐字 3D 落位；右侧真实官网、GitHub 首页或 logo 截图随后落定并保持可读。
- 同一工具后续再次出现：召回已经组装好的同款卡片，只保留 0.4-0.8 秒短飞入/高亮，不再从零搭骨架。
- 连续念到多个工具时：共用一个稳定框架，左侧工具名与右侧截图按口播逐项换位；不同时叠三套完整动画。
- 工具卡落定后至少留 0.8 秒可读时间。截图只用公开页面，不展示登录态、账户信息、余额、Token 或私人项目。
- 本片唯一工具集合：`Codex`、`video-use`、`ElevenLabs`、`HyperFrames`、`Remotion`、`FFmpeg`、`HeyGen`。

## Shotcraft 主卡与辅助卡

用户指定的七张主卡全部保留并按准确 demo 适配：

1. `graze-face-tour`：开场第 1 秒快速绚烂飞入，并在第 4 秒短促回扣；人物不被当作 3D 表面。
2. `flying-words`：开场第 2 秒透明词语纵深隧道，中文词表并避让人物。
3. `steep-tilt-glide`：开场第 3 秒透明 60° 侧立页面掠过，镜头固定、页面自移。
4. `gradient-word-sweep`：透明前景强调“没有出镜 · 没有重录”。
5. `neon-triple-marquee`：透明、置于人物背后的三行信息跑马灯；工具卡进场前退出。
6. `assemble-then-type-flyin`：全部工具名的统一身份卡；左框先组装，右框延迟约 0.3 秒进入。
7. `card-flock-tumble`：问题句后的 4.5 秒独立音乐桥。
8. `autolayout-gap-dial`：“一共六步”的六块参数化总览。
9. `aurora-bloom-bg-flip`：六个章节小标题的统一转场。

正文继续保留三个不冲突的辅助卡：`voice-waveform-live`、`ai-stream-response`、`canvas-materialize-moves · panel-to-canvas`。原方案中的 `spotlight-hero-card`、`radial-ripple-phone-chips`、`mosaic-reframe`、`line-carry-transition` 不再作为本片主镜头。

## 剪辑与声音

- 原片几乎无长静音，不按静音阈值做激进压缩；正式制作以词级口播边界和数字人异常检查为主。
- 录屏自身声音默认静音，连续旁白仍是唯一声音基准；只保留必要的点击、确认和完成态拟音。
- `card-flock-tumble` 的 BGM 是独立 sting，不延续为全片背景音乐。建议使用短 riser → collapse impact → smoke tail，开始和结束均不与人声重叠。
- 章节 `aurora-bloom-bg-flip` 使用同一组低频翻页 hit，但六次强度逐渐收敛，避免机械重复。
- 高能动作后留 0.8-1.5 秒稳定阅读；代码、命令和方案正文出现时停止持续运镜。

## 术语待最终核对

用户逐字稿中的 `emotion`、`fan pack`、`眼头`、`黑针片段`、`报音` 可能分别对应 `Remotion`、`FFmpeg`、`眼神`、`黑帧片段`、`爆音`。视觉标签暂按上下文使用规范工具名，但烧字幕前必须对照原音逐项核实，不能擅自把规范化文本当成已确认逐字字幕。
