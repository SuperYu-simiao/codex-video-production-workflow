## 当前前置交付顺序（暂定）

1. 读取当前项目、逐字稿和用户明确提供的素材，先生成 `需要补录的操作素材.md`。按原句说明缺什么、为什么需要、由谁提供以及怎样录制；不要求用户提前剪好素材。
2. 根据已经存在和计划补充的素材，再生成包装方案/导演分镜，明确时间基准、画面状态、人物位置、素材、动效、转场、声音和待确认项。
3. 如果逐字稿涉及产品、工具或品牌，且分镜需要官网截图、Logo 或身份卡，再生成 `工具官网-GitHub截图素材表.md`；此时只规划来源，不访问登录态页面、不提前采集。
4. 等待用户审阅、补素材或修改方案。只有用户对具体阶段明确批准后，才能进入对应的制作步骤。

## 暂定提炼结构

以下只是第一份样本呈现出的结构，后续会依据新增文档修订：

1. 当前结论与证据精度：片源规格、转录精度、时间误差、时间轴映射和已获授权范围。
2. 创意方向：一句话定位、色彩、字体、人物与素材关系、字幕归属。
3. 开场精排：按口播节拍列出时间、画面、动效、声音和稳定阅读时间。
4. 合成层级与降级方案：明确前后景顺序、遮罩检查和失败时的可接受替代方案。
5. 正文章节分镜：逐段绑定原句、主画面、人物位置、素材、动效与转场。
6. 统一视觉系统：工具身份卡、章节转场、重复元素的首次出现与召回规则。
7. 剪辑与声音：精剪依据、原声优先级、拟音/BGM 边界、阅读停留。
8. 待确认项：术语、字幕、素材缺口、事实与品牌信息，不把推测写成已确认内容。
9. 素材缺口与补录清单：先盘点已有素材，再按逐字稿起止原句列出缺失素材、优先级、录制动作、可替代方案和建议原始长度。
10. 素材责任边界：区分必须由用户提供的真实流程证据、可用截图或文档替代的内容，以及后期可从公开来源采集的身份素材。
11. 录制与隐私规范：连续录制即可，不要求用户预剪；明确分辨率、帧率、静止把手、点击停顿，以及密钥、账号、私人路径和客户内容的遮罩要求。
12. 公开身份素材计划：在适用时为每个工具或品牌记录对应原句、首选公开来源、备选来源、构图要求、采集规格和复用方式。
13. 工具卡触发与复用：区分第一次完整建立身份、后续短召回、同段轻响应和结尾压缩复用，避免每次提到工具名都重复播放完整动效。

## 已确认的硬门槛

- 用户要求做视频时，先交付可审阅的导演类 Markdown 文档；这一步不等于批准剪辑、制作动效、启动预览或渲染。
- “先看方案”“禁止直接做视频”“不允许 render”等要求必须原样执行。
- 每次批准只适用于用户明确批准的阶段和版本，不能自动扩展到整片或最终渲染。
- 导演文档必须区分已验证事实、估算时间、建议方案和待用户确认内容。
- 补录清单必须绑定当前视频的真实逐字稿和已有素材，不能照搬其他视频的分组、工具名、时间码或操作步骤。
- 逐字稿原句是补录素材的主要定位锚点；没有词级时间戳时，时间码只能标为规划级约数。
- 不要求用户先把补录素材剪好；每组录一条连续操作即可，后期再按原句拆分。
- 不为画面效果要求用户重复卸载、重装、破坏环境或伪造界面；无法复现时优先录制真实的已安装、已配置或完成状态。
- 公开身份素材表是条件型交付物，只在内容确实涉及可识别产品、工具或品牌，并且方案需要对应视觉身份时生成。
- 规划公开截图来源不等于批准素材采集；必须等方案批准并进入素材采集阶段后再访问和截取。
- 身份素材优先使用官方公开官网、官方仓库或官方 Logo，不用搜索结果页、第三方素材站、登录后台或私人页面替代。
- 正式采集时记录 URL、采集日期和公开来源，并检查品牌名、仓库名或首页主标题可读。

## 后续处理

每收到一份新文档：

1. 在本目录按序号保存原文。
2. 在“当前样本”中登记其独有价值。
3. 只更新暂定共性，不提前把单个样本的风格或工具固化为通用规范。
4. 用户确认样本收齐后，再创建并验证最终 Skill。
