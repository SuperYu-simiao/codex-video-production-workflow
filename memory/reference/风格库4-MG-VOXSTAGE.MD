# MG-VOXSTAGE｜复古新闻档案纪实拼贴视觉体系

> 风格库编号：4
> 证据口径：本文由用户直接提供的视觉规范整理而成，没有参考视频、镜头参数或生成模型实测。所有参数是创作要求或实施建议，不冒充源工程数据。
> 阶段口径：这是视觉风格 Skill 与规划资产。保存风格不等于批准素材采集、人物匿名处理、图片生成、动画制作、预览或最终渲染。

## 0. 一句话风格

把几十年前的财经报纸、调查档案和真实人物照片剪下来，搭建成具有前景、中景、后景和真实纸片阴影的立体新闻舞台，再用 35mm–50mm 电影纪录片镜头，以浅景深、缓慢 Dolly/Pan 和多层纸片视差进行拍摄。

这不是平面复古海报，也不是现代互联网 UI。它必须同时成立为：

1. **新闻编辑设计**：标题、正文、数据、图注和文件编号有严格网格与信息层级。
2. **真实纸质微缩景观**：不同纸片之间有距离、阴影、遮挡和景深。
3. **纪实证据叙事**：人物、数据、报纸、地图和时间线服务于可核验内容，不制造虚假新闻证据。

## 1. 风格定位

- **画幅**：16:9 横版，电影级纪录片构图。
- **风格标签**：Editorial Documentary Collage / Archival News Collage / Mixed-media Motion Graphics。
- **核心视觉语言**：复古新闻档案 + 纪实拼贴 + 报纸剪贴 + 编辑设计 + 信息可视化。
- **整体气质**：严肃、克制、调查感、财经感、档案感；可以有戏剧张力，但不耸动、不娱乐化处理真实受害者或敏感人物。
- **主要用途**：财经调查、商业史、公司关系、行业变迁、历史回顾、政策解释、人物档案、证据链与观点型纪录短片。

### 不适用场景

- 明亮现代 SaaS 演示、玻璃拟态产品广告、赛博朋克科技片头。
- 需要长时间阅读真实网页、代码、提示词或复杂 UI 的教程段落。
- 轻松卡通、儿童内容、潮流高饱和海报或塑料质感 3D 角色。
- 没有可核验人物、数据和档案来源，却要伪装成真实新闻证据的内容。

## 2. 人物视觉处理

### 2.1 标准处理链

`真实人物照片 -> 黑白/低饱和 -> 高反差印刷效果 -> 半调网点 -> 剪纸抠图 -> 粗白轮廓 -> 可选红色套色错位 -> 轻纸张阴影`

人物呈现为从旧报纸中剪下后竖立在场景中的纸片人物（Cardboard Cutout），但必须保留原摄影的真实人物身份、姿态与光影信息，不能卡通化或改造成光滑 3D 人物。

### 2.2 统一规范

- 黑白或低饱和，肤色不保留高饱和彩色。
- 明显但可控的新闻纸颗粒和半调印刷网点。
- 粗白色剪纸轮廓，边缘允许轻微不规则与人工裁切感。
- 白边外侧可加入 1–4 px 视觉量级的轻微错位红色描边；具体像素按输出尺寸调整。
- 纸片背后有柔和、短距离、低不透明度的真实阴影，使人物与后景分离。
- 人物边缘不可完美到像矢量抠图，也不可破碎到损害身份识别。
- 群像中通过大小、遮挡、站位和焦点建立主次，不给每个人相同视觉权重。

### 2.3 匿名遮眼条边界

- 仅当素材本身要求匿名、用户明确要求匿名，或经编辑判断确需保护身份时，在眼睛位置加入粗黑色横向遮眼条。
- 不把遮眼条当通用装饰，不对公开人物或普通采访对象无差别添加。
- 不用遮眼条暗示某人违法、涉案或有负面身份；人物身份、指控与关联关系必须来自当前项目可核验资料。
- 已匿名人物的文件名、图注、字幕和旁白也不能泄露真实身份。

### 2.4 真人口播适配

- 默认把授权照片、档案照或经批准的口播定格帧做成纸片人物，不默认把整段连续真人视频半调化。
- 若当前视频必须保留连续口播，真人音轨保持连续；新闻拼贴全屏时可将原真人缩到安全角 PIP，或在获批分镜中暂时隐藏。
- 把连续真人变成动态剪纸角色属于单独的视觉处理，必须在小样中检查嘴型、边缘抖动、半调闪烁与人脸可辨识度。

## 3. 立体纸质微缩舞台

采用 Paper Diorama 构图，不是把所有素材平铺在一张纸上。

| 层级 | 内容 | 空间与景深要求 |
|---|---|---|
| 前景 | 大型人物剪纸、报纸边缘、档案卡片局部、撕纸遮挡 | 可故意超出画面边界；允许自然虚化，形成镜头贴近模型的感觉 |
| 中景 | 主要人物群、数据卡片、地图、主标题、箭头、照片与证据链 | 主焦点所在；边缘、文字和关系必须清晰可读 |
| 后景 | 巨幅旧报纸、新闻标题、地图、历史档案、墙面纸张 | 轻微失焦；作为语境而非第二主标题，不与中景争抢 |

### 空间硬规则

- 前、中、后景必须具有不同 Z 距离、尺寸、遮挡与视差速度。
- 主体清晰，前景自然虚化，背景轻微虚化；不可用统一高斯模糊假装景深。
- 大标题允许被人物或纸张局部遮挡，但关键信息仍需通过上下文读懂。
- 每镜只设一个主要阅读顺序：人物 -> 标题 -> 数据，或标题 -> 地图 -> 证据；不要让所有层级同时争夺注意力。
- 重要人物、数字和证据至少有一段完全无遮挡的稳定状态。

## 4. 基底材质

整体必须具有可触摸的真实纸张质感：

- 泛黄旧报纸、米棕色档案纸、新闻纸纤维。
- 胶印颗粒、半调网点、墨迹、轻微污渍。
- 轻折痕、撕纸毛边、剪刀裁切边缘。
- 老式胶印误差和轻微 CMYK/红色套色错位。
- 纸层接缝、贴照片留下的压痕、胶带或装订痕迹可以少量使用。

### 材质控制

- “旧”不等于满屏脏污。污渍、折痕和墨迹必须有层级，不能损害人物和数据可读性。
- 同一批次统一纸张年代、颗粒尺度与黄化程度，避免一张像 1930 年代报纸、下一张像全新打印纸。
- 纸片边缘保留人工感，但不做过度锐化、白边锯齿或 AI 溶解边缘。
- 禁止干净光滑、数字化程度过高的现代 UI 表面。

## 5. 色彩体系

米棕 + 黑白灰占画面约 85%–90%，红色与芥末黄只做少量功能性标记。

| 色彩 | 色值 | 用途 |
|---|---|---|
| 存档米棕 | `#C9BB9C` | 报纸、地图、档案背景主色 |
| 油墨黑 | `#1A1A1A` | 人物、标题、正文、结构线与阴影 |
| 半调灰 | `#8C8C8C` | 照片、远景、次级信息 |
| 新闻红 | `#D62E1F` | 重点数据、箭头、路径、圈选、下划线与轻微套色错位 |
| 芥末黄 | `#D9A441` | 极少量辅助标签、历史节点或警示标记 |

### 红色配额

- 红色只用于人物错位轮廓、箭头、数据、下划线、地图路径、圈选标记和重点关键词。
- 单镜红色建议保持为视觉强调而非背景主体；禁止大面积红色背景。
- 同一镜头已有红色数据主角时，箭头、描边和下划线应降级，避免多个红色焦点竞争。

## 6. 字体与排版

整体采用传统报纸编辑语言，而非互联网 UI 卡片语言。

| 层级 | 字体方向 | 排版作用 |
|---|---|---|
| 一级标题 | 超大、窄体、粗体、全大写 Condensed Sans Serif | `THE DEAL`、`BIG TECH`、`$116B` 等强结论；可被人物局部遮挡 |
| 正文/资料 | 传统 Serif / Newspaper Typeface | 新闻摘要、档案引文、时间地点、事实背景 |
| 数据数字 | 粗体 Condensed Sans Serif | 高视觉权重的金额、比例、年份、数量 |
| 辅助信息 | 小字号编辑标签或等宽编号 | `Fig. 03 — MARKET SHARE`、`ARCHIVE 2026 / FILE 017` |

### 排版规则

- 严格网格，左对齐为主；允许大标题与极小注释形成强烈尺寸反差。
- 高信息密度必须由层级、留白、网格和焦点管理，不等于把文字塞满全屏。
- 标题、数据、新闻摘录、人物姓名、文件编号必须来自当前项目真实文稿或已核验资料；不得生成无意义英文、Lorem Ipsum 或假新闻标题。
- 可读新闻正文不做 AI 图像内生文字，优先由后期排版层精确合成。
- 中英文混排时先确认字体授权、字重覆盖和标点风格；不得因缺字回退造成现代 UI 感。

## 7. 信息可视化组件

所有组件都应像真实印刷后剪下来、贴入或竖立在场景中，而不是数字悬浮层。

### 组件清单

- 红色统计数字、黑白数据卡片。
- 地图定位图钉、红色路线和关系连线。
- 手绘箭头、红色圈选、红色马克笔下划线。
- 报纸剪报、档案照片、引文条、证据编号。
- 时间轴、新闻标题、股票/财经数据、文件编号。
- 小型 Figure 标签和来源/日期注释。

### 事实与来源硬规则

- 每个新闻标题、数字、金额、比例、日期、地图路径和人物关系都要绑定当前项目来源。
- 真实报纸、档案照片、Logo、财经数据和地图必须记录来源、日期、授权/公开范围与必要署名。
- 无法核验的关系不能画成确定的红线；可在方案中标为“待核验”或明确写成“概念示意”。
- 不拼接不同事件的报纸标题制造新的因果关系，不用模糊 Logo 或虚构文件编号冒充证据。
- 对仍在世人物、公司或争议事件，画面措辞不能超出脚本和来源所支持的结论。

## 8. 镜头语言

模拟真实摄影机拍摄纸质微缩模型。

- **镜头**：35mm–50mm 纪录片镜头视感。
- **景深**：浅景深；前景自然虚化，主体清晰，背景逐渐失焦。
- **氛围**：微弱暗角、柔和自然阴影、轻微胶片颗粒、轻微镜头呼吸。
- **运动**：极慢横向 Dolly / Pan，或 2%–4% 微弱推进。
- **视差**：多层纸片按 Z 距离以不同速度运动，前景最快、中景次之、后景最慢。
- **稳定期**：标题、数据或证据进入后必须降低或停止运镜，留出阅读时间。

### 禁止镜头

- 快速炫技穿梭、旋转镜头、强推拉、速度坡度滥用。
- 霓虹扫光、赛博空间、金属反射和塑料 3D 摄影机运动。
- 每个元素都独立漂浮，导致纸质微缩舞台失去重力与真实搭建感。

## 9. 动态规范

动画整体基调：克制、机械、编辑感、纪录片感。

| 元素 | 动态方式 | 落定要求 |
|---|---|---|
| 人物剪纸 | 从下方或侧面快速进入，轻微过冲后回弹 | 回弹一次后稳定，不持续漂浮 |
| 数据数字 | 快速向上计数并停住 | 终值必须来自真实资料，停留可读 |
| 红色下划线 | 像马克笔一样从左向右划出 | 只划重点词/数据，不整段涂满 |
| 箭头/路线 | 沿真实关系或地图路径快速绘制 | 起终点明确，避免装饰性乱线 |
| 报纸 | 从不同方向滑入、覆盖、叠压 | 落定后保持纸张重力感 |
| 照片 | 模拟人工把照片贴到桌面或插入档案墙 | 有轻压、阴影变化或贴合动作 |
| 镜头 | 缓慢稳定 Dolly/Pan 或 2%–4% 推进 | 阅读阶段减速或停止 |

### 运动节奏建议

- 单一纸片入场：约 `0.25–0.55s`，使用短促 `easeOut` 或轻微一次性 overshoot。
- 报纸叠压：约 `0.35–0.70s`，不同方向错峰进入，不做无重力旋转。
- 下划线/箭头绘制：约 `0.25–0.60s`，跟随口播关键词或关系说明。
- 数据计数：按语义安排约 `0.5–1.2s`，终值出现后至少稳定 `0.8–1.5s`。
- 镜头推进：单镜总幅度 `2%–4%`；复杂信息进入稳定期后不再持续推进。

## 10. 标准镜头模块

### `VS-S01 archive-wall-establishing`

- 后景巨幅报纸墙与地图，中景标题和档案编号，前景撕纸边缘虚化。
- 用途：章节建立、历史背景、调查主题开场。
- 动作：后景先稳住，标题纸片进入，镜头做极慢横向 Dolly。

### `VS-S02 cardboard-portrait-lineup`

- 多名真实人物剪纸以前后错位、不同尺寸竖立；主角在中景焦点，其余人物轻微失焦。
- 用途：人物关系、公司角色、利益相关方。
- 动作：人物按叙事顺序依次进入，不做整排同时弹跳。

### `VS-S03 protected-identity-file`

- 匿名人物剪纸、黑色遮眼条、档案标签与已脱敏信息。
- 用途：确需保护身份的调查对象。
- 限制：只有真实匿名要求才可使用；遮眼条不能制造负面暗示。

### `VS-S04 financial-number-verdict`

- 超大 Condensed 数字成为中景主角，周边是报纸证据和小型 Figure 标签。
- 用途：金额、比例、市场规模、增减结果。
- 动作：数字计数落定，红色下划线或圈选只强调一次。

### `VS-S05 map-route-investigation`

- 米棕地图、红色路线、定位图钉、照片与文件节点组成调查路径。
- 用途：资金流、地点迁移、供应链、事件路径。
- 动作：路线从起点到终点绘制，节点按到达顺序进入。

### `VS-S06 headline-evidence-stack`

- 多份真实报纸标题与档案照片从不同方向滑入并叠压，主证据保持最上层。
- 用途：多来源印证、舆论演变、历史报道。
- 限制：标题不可跨事件拼接成虚假结论。

### `VS-S07 archive-timeline`

- 左对齐时间轴、年份大数字、照片、Figure 标签与文件编号形成纵向或横向叙事。
- 用途：公司史、事件进程、技术演变。
- 动作：年份节点机械式依次落定，镜头沿轴线缓慢移动。

### `VS-S08 closing-diorama-tableau`

- 人物、数字、报纸和地图收束成一座完整纸质舞台，主结论标题居中或左对齐。
- 用途：结论、反问、章节收束。
- 动作：最后一张纸片压入，镜头停止，保留稳定结束画面。

## 11. 转场语法

| 场景关系 | 推荐转场 | 说明 |
|---|---|---|
| 同一调查主题内换证据 | 报纸滑入覆盖 / 照片压贴 | 通过实体纸张接管画面，不用数字 wipe |
| 人物关系转数据 | 人物退到前景虚焦，数字纸片从中景进入 | 保持同一微缩舞台空间 |
| 数据转地图 | 红色下划线延长为路线 | 红线承担语义连接，不额外堆转场 |
| 时间轴换年份 | 文件夹页翻 / 档案卡抽换 | 保持机械、编辑部式节奏 |
| 档案舞台返回真人 | 前景报纸拉开或硬切到连续口播 | 语义落点清楚；真人音轨不重启 |
| 章节结束 | 最后一张证据纸压入后停镜 | 先读完结论，再进入下一段 |

每次画面状态变化仍需语义匹配的转场。同一状态内删除口误或卡顿可以使用干净跳切。

## 12. 灯光

- 柔和顶部主光 + 微弱侧光，模拟真实摄影棚拍摄纸质模型。
- 人物和档案卡在后方纸张上形成轻微、方向一致的真实阴影。
- 阴影用于分离空间，不做厚重戏剧投影；纸张高光保持哑光。
- 允许轻微暗角和胶片颗粒，不允许霓虹、强体积光、塑料反光或金属高光。

## 14. 当前视频工作流接入

- 用户明确选择 `MG-VOXSTAGE` 时，它覆盖默认的黑灰科技 `title-stage` 外观；章节标题改为新闻档案纸质舞台，但其他阶段门槛不变。
- 真实网页、代码、提示词和复杂表格仍优先进入 `material-fullscreen` 或 `code-prompt-stage`，不能为了风格统一把关键内容做成看不清的报纸碎片。
- 纸质档案镜头属于主画面。若保留真人，真人放到由负空间决定的安全角 PIP；字幕仍属于主合成层。
- 当前项目使用该风格前，必须在 `04-动效与包装/` 写明每段口播触发、真实素材来源、人物处理、文字/数据原文、前中后景、镜头运动、转场、字幕安全区和稳定阅读时间。
- 公开人物照片、新闻截图、地图、数据与 Logo 的“计划来源”不等于批准采集；采集仍需要对应阶段确认。
- 风格批准不等于小样批准；小样批准不等于最终渲染批准。

## 15. 两道视觉确认门

### Gate 1：新闻档案分镜与素材来源计划

任何素材采集、人物处理或画面生成前，先交付：

- 逐段原句、核心事实、视觉命题与镜头模块。
- 需要的人物、报纸、照片、地图、数据、Logo、标题和文件编号。
- 每项素材的已知来源、授权状态、待核验项与脱敏要求。
- 前景/中景/后景布局、文字层级、红色配额和镜头运动。
- 对匿名人物的必要性说明；没有必要性时禁止遮眼条。
- 当前是否允许公开素材采集、风格帧制作、预览或渲染。

### Gate 2：Style Frame 审核

Gate 1 批准后，为选定代表镜头准备静态 Style Frame 或可复现规格，检查：

- 人物半调、粗白边、红色错位轮廓与纸张阴影。
- 85%–90% 米棕/黑白灰与限量新闻红。
- 前中后景距离、自然浅景深和纸层遮挡。
- 新闻标题、数字、图注与来源是否真实可读。
- 纸张是否真实但不过度脏旧，是否避开现代 UI 与塑料 3D 感。

只有获批代表帧对应的镜头才能进入动画小样。Gate 2 不批准整片制作或最终渲染。

## 16. QA 清单

- [ ] 画面首先读成真实搭建的立体纸质新闻舞台，而不是平面复古海报。
- [ ] 前景、中景、后景的 Z 距离、遮挡、焦点和视差速度明确。
- [ ] 人物保留摄影真实性，具备半调网点、粗白边、人工裁切感与轻纸张阴影。
- [ ] 匿名遮眼条只用于真实需要，不制造违法或负面暗示。
- [ ] 米棕、黑白灰占约 85%–90%；红色只承担重点功能，没有大面积红底。
- [ ] 标题、数字、日期、地图路线、人物关系、文件编号均来自可核验资料或明确标为概念示意。
- [ ] 正文与新闻标题由可控文字层排版，无乱码、Lorem Ipsum 或 AI 伪文字。
- [ ] 镜头是缓慢 35mm–50mm 微缩摄影感；阅读阶段停止无意义运动。
- [ ] 动效克制、机械、编辑感明确；纸片进入后有重力和落定。
- [ ] 没有现代科技 UI、玻璃拟态、赛博朋克、蓝紫霓虹、光滑 3D、卡通人物或塑料质感。
- [ ] 字幕避让人物、主标题、数据与证据，不写进真人 PIP。
- [ ] 素材来源、授权、脱敏、预览和渲染批准状态记录完整。
