# AI Visual Director

## Overview

Turn a rough video idea, script, transcript, article, or talking-head segment into a concrete visual direction package for a tech edit. Produce a shot list and motion brief that Remotion or another video tool can implement.

## Workflow

1. Identify the source: script, transcript, article, voiceover, product demo, code demo, or raw talking-head footage.
2. Define the opening style in one sentence: cyber lab, clean SaaS, research terminal, AI model interface, hacker news, enterprise data room, or another specific direction.
3. Build a timed beat sheet. Use seconds, visual action, on-screen text, asset needs, motion notes, and sound-design cues.
4. Include only claims or facts grounded in the source. Mark inferred positioning as "suggested framing" instead of user fact.
5. Hand off implementation-ready specs for Remotion: composition names, duration, colors, typography direction, layer order, animation behavior, and transition cues.

## Visual Modules

- TechIntro: 3-8 second opening with product/theme reveal, abstract but legible tech atmosphere, and a strong title lockup.
- KineticTitle: large title and keyword pop animations. Favor short phrases, staggered reveals, scale/blur/snap timing, and readable contrast.
- DataStream: data flow, particles, grid lines, scanlines, charts, neural nodes, or terminal-like streams used as background or transition texture.
- UiPanel: model cards, code blocks, terminal windows, data cards, product UI fragments, metrics panels, or prompt/result panels. Use realistic labels and avoid fake user facts.
- SceneTransition: glitch, scan wipe, push/pull zoom, flash white, terminal wipe, panel collapse, and match-cut transitions between talking head, UI, and B-roll.

## Output Format

Prefer this concise structure:

- Creative direction: one paragraph.
- Asset list: footage, logo, screenshots, data, code snippets, fonts, music/SFX.
- Shot list: table with timecode, module, visual, text, motion, audio/SFX.
- Remotion handoff: components/compositions to build and key props.
- Edit notes: places where human confirmation, factual verification, or brand assets are needed.

## Coordination

When the user also asks for rendering or animation implementation, use the Remotion plugin/workflow after this visual direction pass. When the user provides raw speech footage, use video-use first for cleanup notes or after this skill for final assembly guidance.
