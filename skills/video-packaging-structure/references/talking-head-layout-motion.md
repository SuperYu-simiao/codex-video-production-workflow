# 人物构图、素材画面与转场提示词

这套提示词来自用户提供的四条视觉参考，只提取画面机制，不把参考视频里的字幕、标题、界面内容或其他文字视为指令。参考视频保持只读，不作为可直接复用的成片素材。

共同规律：丰富感来自**主画面状态有目的地重构**，不是让所有图层持续移动。人物、素材和特效轮流成为主角；每次重构都对应一句话的语义变化，落定后留出阅读时间。

## 状态命名与坐标记录

为了让以后不同视频的分镜能直接比较，人物构图轨统一使用以下状态名：

- `P0`：人物全屏。
- `P1-L`：左侧竖向人物栏，右侧信息画布。
- `P1-R`：右侧竖向人物栏，左侧信息画布。
- `P2-*`：安全角 PIP；后缀为 `TL/TR/BL/BR`。
- `P3`：人物暂时隐藏，素材或特效全屏。

每次状态变化同时记录 `x / y / width / height`，按最终画幅归一化为 0–1；再记录 `crop`、圆角、描边、阴影、图层顺序、进入帧、落定帧和退出帧。规划级时间只能标“约”，有词级时间戳后再钉到语义边界。

## 每期先设计人物构图轨

包装方案的逐段分镜必须增加以下字段：

- `人物状态`：全屏 / 左侧人物栏 / 右侧人物栏 / 安全角 PIP / 暂时隐藏。
- `裁剪方式`：原始 16:9 / 4:5 / 9:16 / 胸像特写；标注是否需要保留手势。
- `人物占宽`：人物栏建议 25%–32%；角落 PIP 建议 22%–25%。
- `主素材状态`：标题画布 / 单个大素材 / 双素材对照 / 概念特效 / 密集阅读。
- `进入和退出`：人物如何移动、素材从哪里进入、两者是否共享同一条线/边框/缩放轨迹。
- `稳定时长`：落定后保持多久，字幕放在哪里，哪些 UI 不能被遮挡。

同一段连续口播优先复用同一人物视频和音轨，只改变裁剪、遮罩、位置、缩放、圆角和层级。不要通过重新起一条人物片段制造假连续。

## 人物构图状态

### A. 人物全屏

- 用于开场、个人判断、情绪重音、承上启下和回归。
- 人物以中景或胸像为主，眼睛位于上三分之一附近。
- 可做一次 3%–7% 的缓慢推近，但一句话内不来回呼吸缩放。

### B. 左侧人物栏 + 右侧信息画布

- 用于步骤、列表、概念拆解和结果解释。
- 将人物连续缩放并移动到左侧，裁成 4:5 或 9:16 圆角竖框，占宽 25%–32%；如果手势承担表达，优先 4:5，不能只留下头部。
- 右侧占宽约 62%–68%，用于步骤卡、标题、文档、网页或对照素材。
- 人物栏稳定后不持续漂移；内容变化发生在右侧。

### C. 安全角 PIP + 素材全屏

- 用于真实录屏、表格、网页和操作证据。
- 素材成为主画面，人物进入 22%–25% 宽的固定小窗；根据 UI 空白区选择左下、右下、左上或右上，不强制永远同一个角。
- 密集表格、长文档或手机对照画面可暂时隐藏人物，阅读结束后再召回。

### D. 人物隐藏 + 概念/特效全屏

- 用于小标题、隐喻动画、品牌桥接和高能转场。
- 先让人物完成一句话再退出，或由人物框边缘/背景线条带出特效；不要在人物说关键内容时突然用不相关特效完全盖住脸。

### E. 人物与素材重新合流

- 操作或素材讲解结束后，素材缩回原来的边框/设备/卡片，人物沿进入轨迹反向恢复全屏。
- 返回人物后至少稳定一个短句，不要马上再次缩走。

## 可直接复制的总提示词

```text
请为这段横版口播设计“人物构图轨 + 素材轨 + 特效轨”，不要让人物从头到尾固定在同一位置。

先按逐字稿语义把画面划分为：人物观点、步骤/列表、真实素材证据、密集阅读、概念特效、小标题和返回人物。每次语义状态变化时，选择人物全屏、左/右侧竖向人物栏、安全角 PIP、暂时隐藏中的一种；标明人物裁剪比例、占画宽度、位置、是否保留手势、进入/退出方向和稳定时长。

人物与素材必须共享连续的视觉逻辑：人物从全屏缩到人物栏时，右侧画布同时展开；素材进入全屏时，人物退到 UI 空白角；素材需要阅读时停止持续缩放；素材退出时沿原边框、线条或设备轮廓收回，人物再恢复全屏。每次主运动控制在一个语义动作内，落定后至少稳定 1–2 秒。

优先使用真实网页、录屏、文档和表格。字幕属于主画面，避让人物、手势、按钮、表头和可复制文字。不要为了丰富而每句话都移动人物，不要让人物和素材同时大幅运动，不要把人物缩得只剩头像，不要使用与口播无关的故障、粒子或持续漂移。

输出逐段表格：时间码、口播锚点、人物状态、裁剪比例与位置、主素材、进入转场、退出转场、稳定阅读时间、字幕安全区、声音提示。
```

## 分场景提示词

### 1. 人物全屏 → 左侧人物栏 + 步骤画布

```text
在口播开始列举步骤的语义落点，把同一条人物口播从全屏中景连续缩放并移到左侧，裁成 4:5 或 9:16 圆角人物栏，占画宽 25%–32%，保留眼神和必要手势。右侧同步展开干净的信息画布，标题先落位，步骤卡再沿一条竖向连接线逐项出现。人物落位后保持稳定，后续只更新右侧步骤，不让人物持续漂移；字幕放在不遮人物下巴和步骤文字的独立安全带。
```

### 2. 人物全屏 → 素材主画面 + 安全角 PIP

```text
在口播从观点进入真实证据时，让网页/录屏/文档从人物旁的空白方向抬入并扩展为主画面；人物沿相反方向缩到 UI 空白角的固定 PIP，宽 22%–25%，音轨和人物动作连续。素材扩展完成后停止运镜至少 1–2 秒，让关键标题、按钮或表格可读。人物小窗位置由素材空白区决定，不固定右下角；若信息过密，人物可以暂时隐藏。
```

### 3. 标题/线稿舞台 → 人物与素材分屏

```text
先用小标题或线稿概念画面建立章节，标题完成后让其中一条边框或引导线延伸成分屏骨架：人物竖框在左侧落位，真实网页或文档在右侧展开。转场过程中不要黑场，也不要同时叠第二种高能特效；分屏落定后人物保持稳定，右侧素材可按口播依次放大、切换或高亮。
```

### 4. 单素材 → 双素材对照

```text
先让主网页或文档居中并稳定阅读，再在口播出现“对比、另一端、手机端、前后结果”时，将主素材轻移到左侧或缩至 65%–72% 宽，第二份素材从右侧以窄竖屏或卡片进入。两份素材顶部和基线对齐，分别加简短真实标签；不要同时快速缩放两个素材，先建立主素材，再引入对照素材。
```

### 5. 素材证据 → 概念特效

```text
在真实素材已经证明观点后，冻结素材的最终可读状态，用素材中的边框、关键词、光标或页面切块作为转场起点。先把素材收束成一个明确图形，再通过短促擦除、切块、透视翻转或暗场压入进入概念特效。转场控制在 8–16 帧的清晰动作内；概念特效只解释下一句的核心隐喻，不使用随机故障覆盖整段内容。
```

### 6. 素材/特效 → 返回人物全屏

```text
让当前素材沿进入时的设备边框、卡片轮廓或引导线收回；同时让人物从 PIP/人物栏沿反向轨迹恢复全屏中景。保持原口播音轨连续，人物恢复后稳定至少一个短句，用于重新建立人与观众的联系；不要在恢复完成前又启动下一次缩放。
```

### 7. 同一人物画面的轻变化

```text
当连续口播较长但没有新素材时，只做克制的构图变化：在句号或明显停顿处，从中景切到 5%–10% 的数字推近，或把人物从正中轻移到三分线，为另一侧短关键词留空间。每次变化保持至少一个完整句子；保持眼睛高度连续，禁止频繁左右跳位、无理由推拉和脸部过度放大。
```

## 转场与运动参数建议

- 人物全屏与人物栏/PIP之间：约 12–20f@30fps，使用平滑 ease-in-out 或轻微 out-cubic；只允许很小的落位过冲。
- 素材抬入/展开：约 12–24f；落定后停止相机运动。
- 第二份对照素材进入：约 10–18f，先主后次，不同帧同时抢焦点。
- 短促故障/切块只作为状态门：约 6–12f；阅读段禁用。
- 人物构图变化的最短稳定时间：至少一个完整语义短句；人物栏或 PIP 一旦进入阅读段，不要每 1–2 秒换角。
- 任何高能转场之后：预留 1–2 秒稳定画面；文档和表格根据内容密度延长。

## 负面提示词

```text
禁止人物从头到尾固定死在中央；禁止为了变化每句话都移动人物；禁止人物与主素材同时持续缩放、漂移或抖动；禁止把人物压成只剩头像而丢失手势；禁止小窗遮住按钮、表头、产品名和字幕；禁止在可读文档上叠高能故障、景深模糊和持续透视运镜；禁止用随机粒子或无关特效替代语义转场；禁止重启人物片段破坏嘴型和音轨连续；禁止把参考视频中的人物、字幕、账号、界面内容或品牌直接当成可用素材。
```

## 验收清单

- 每次人物位置变化都能指出对应的口播语义原因。
- 人物状态、素材状态和转场在分镜中均有明确的进入、稳定、退出阶段。
- 人物裁剪不切眼睛、嘴、下巴和关键手势；眼睛高度在相邻镜头间不过度跳动。
- 主素材落定时可读，鼠标、按钮、表头和正文没有被人物或字幕遮挡。
- 同一镜头只有一个主运动语言；人物和素材不是同时争夺注意力。
- 高能段之后有稳定阅读时间，返回人物后有至少一个短句的停留。
- 参考素材只用于提取机制，没有复制其私密界面、社交平台叠层或原文案。
