# 素材就绪后的默认包装结构

本文只在素材复核通过后读取。素材准备阶段按 `skills/video-editing-workflow/SKILL.md`，只做盘点、补录清单、公开静态素材收集、用户动态录屏和状态复核，不设计构图、镜头、特效或成片秒数。

包装阶段一次性生成同版本的包装方案、更新后的补录清单、公开素材表和特效映射。文件记录盘点依据和 `待锁定`/`已锁定`；只有用户确认后才锁定。锁定不授权制作。

| 语义 | 候选机制 | 约束 |
|---|---|---|
| 章节或小标题 | `aurora-bloom-bg-flip` | 新标题在翻暗后出现并稳定；同拍不叠第二主转场 |
| 首次说出工具/Skill | `assemble-then-type-flyin` | 右框用真实官网、GitHub或Logo；重复提及短召回 |
| 明确步骤 | `autolayout-gap-dial` | 标签来自口播，测量/数字同源，不伪造参数 |
| 可复制文本 | `document-typewriter-reveal` | 原文逐字保留，按语义分页，字幕避让 |
| 问题/主张后的桥接 | `card-flock-tumble` | 真正暂停源片和人声；结束后从同一源帧恢复 |

候选只在语义与素材同时匹配时使用。参考会话沉淀中的次数和帧号属于第五期，不是新一期配额。

锁定时记录触发句和真实时间依据、素材ID/路径/区间/来源/质量/脱敏、缺口状态、人物构图、转场与稳定阅读、字幕和声音、卡片及准确demo、当前授权范围。实施前另写实际 source/master 导演时间线。
